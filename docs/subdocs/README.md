## 3. 编写约定

- 每份子文档按模板填写文档信息、修订记录、编制依据、关联文档与七个章节。
- 结论先行；契约使用表格或示例，不写背景铺垫。
- 待确认项单独成节，写清“需要谁在何时回答”，不隐藏在正文中。
- 子文档之间不互相复制；跨文档引用使用相对链接。
