## 1. 结论

建一个只读目录服务，回答"我们推荐哪些插件、它们解决什么问题、谁维护、当前版本能不能装"。

制品库存包，目录存**说法**：用途、适用场景、维护人、上架状态。两者分工，不重复。

边界：不存包体、不做下载代理、不做评分与评论。

## 2. 目标与非目标

**目标**

- 给出精选清单，每条带用途、场景、维护人与兼容范围。
- 与市场界面共用一份数据，避免两处维护。
- 上架、下架、替换可追溯。
- 目录不可用时，已安装插件不受影响。

**非目标**

- 不存储或代理包文件。
- 不做社区功能（评分、评论、下载量排行）。
- 不替代制品库的版本与校验信息。

## 3. 需求与依赖

| 需求/验收 | 关系 | 说明 |
|---|---|---|
| REQ 可治理分发 | 支撑 | 上架有据可查 |
| REQ 推荐能力落地 | 直接实现 | 精选与展示的主要载体 |
| 验收 A10 分发 | 支撑 | 与市场包联动 |

| 依赖 | 类型 | 版本约束 | 缺失时的行为 |
|---|---|---|---|
| 企业制品库 | 服务 | 企业现有 | 无版本信息，目录标记为不可安装 |
| 企业身份 | 服务 | OIDC | 未登录不可浏览 |

## 4. 扩展形态与边界

| 项 | 内容 |
|---|---|
| 形态 | 只读目录服务（HTTP JSON），无写入面 |
| 运行位置 | 企业内网 |
| 目标 DSH 与 SDK | 不涉及 |
| 使用的 seam 或服务 | 制品库元数据、身份校验 |
| 不修改的核心 | 制品库、市场 UI |

## 5. 接口与配置

| 配置项 | 类型 | 默认值 | 必填 | 说明 |
|---|---|---|---|---|
| `catalog.source` | string | 仓库内 JSON | 是 | 精选清单来源 |
| `catalog.registry` | string | 空 | 是 | 制品库地址，用于取版本 |
| `catalog.refreshSeconds` | number | `300` | 否 | 版本信息刷新间隔 |

```json title="目录条目（示意）"
{
  "name": "@heluo/forge-gateway",
  "title": "企业模型网关接入",
  "summary": "把模型调用固定到内网网关",
  "scenarios": ["日常问答", "代码辅助"],
  "maintainer": "平台组",
  "versions": ["0.3.0"],
  "engines": { "dsh": ">=0.2.1" },
  "status": "published",
  "compatible": true
}
```

清单本身放在仓库里评审，服务只负责拼接制品库的实时版本与兼容判定。

## 6. 权限、凭据与数据

| 项 | 处理方式 | 生命周期 | 失败时 |
|---|---|---|---|
| 制品库读取 | 只读令牌，服务端保管 | 随部署 | 目录标记版本未知 |
| 精选清单 | 仓库内文件，走评审 | 随版本 | 用上一版 |
| 访问日志 | 主体、条目、结果 | 90 天 | 不影响读取 |

## 7. 流程

```mermaid
flowchart LR
  A[读取精选清单] --> B[取制品库版本]
  B --> C[计算兼容与状态]
  C --> D[输出目录 JSON]
  D --> E[市场界面展示]
```

**刷新**：按 `refreshSeconds` 更新版本信息；清单变更随部署生效。

**降级**：制品库不可达时输出版本未知，不隐藏条目。

## 8. 失败模式

| 场景 | 行为 | 调用方可见结果 | 是否可重试 |
|---|---|---|---|
| 制品库不可达 | 条目标记版本未知 | 可浏览不可安装 | 可重试 |
| 清单缺字段 | 该条目跳过并告警 | 条目暂不显示 | 修正后重试 |
| 包已下架但清单仍列 | 标记为已撤回 | 不可安装 | 否 |
| 未登录 | 401 | 提示登录 | 登录后重试 |

## 9. 可观测性

| 事件 | 字段 | 去向 | 保留 |
|---|---|---|---|
| 目录请求 | 主体、条目数、耗时 | 访问日志 | 90 天 |
| 上架状态变化 | 条目、从、到 | 变更记录 | 180 天 |

## 10. 测试矩阵

| 层级 | 覆盖 | 命令 |
|---|---|---|
| 单元 | 清单校验、兼容判定、下架标记 | 服务自带测试 |
| 契约 | 字段与市场界面一致 | 契约用例 |
| 集成 | 制品库不可达、清单缺字段 | 仿制品库 |
| 端到端 | 市场界面读取目录并完成一次安装 | 手工 |

## 11. 打包、升级与回退

容器部署，清单与配置外置；升级保留旧镜像。

回退：市场包改回只读制品库即可停用本服务，已安装插件不受影响。

### 需用户确认的设计选项（增益不明确，暂不采用，保留待定）

| 选项 | 可能的增益 | 代价 | 当前处理 |
|---|---|---|---|
| 做写接口与上架后台 | 自助上架 | 引入鉴权与流程系统 | 不采用，清单走仓库评审 |
