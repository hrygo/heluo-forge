## 1. 结论

企业级 AI 网关在协议层面确立**路线 B（双因子凭据协同）**为受管个人助手（如智能研发助手、通用办公助手等）的终态契约：发起模型推理、MCP 代理或 Agent 调用时，客户端必须协同携带个人长效凭据与当前登录员工的统一 IAM Access Token。网关基于本地预热缓存的 IAM JWKS 公钥执行非对称验签并比对工号，杜绝凭据脱机滥用与转借；任一凭据缺失或不匹配一律拒绝。无人值守应用 Agent 使用按应用/环境受控开通的专用应用凭据，记录创建人与责任归属，运行时不强制要求创建人在线。

网关服务端统一路由基线为 `/aig/v1`，同时确立**客户端 `baseUrl` 解耦契约**：客户端必须将网关根路径设为可配置项（预设企业默认值 `https://ai-gateway.corp.example/aig/v1`），业务代码一律基于 `${baseUrl}/chat/completions` 等相对路径拼接，严禁在客户端代码中硬编码写死 `/aig/v1`，保障本地开发/联调（如使用 cliproxyapi、本地 mock 等代理工具）无缝切换。

模型权限、团队/成员预算、网络规则、正文日志关闭（`privacy_mode`）及审计在选定路线下均须成立。五分钟撤权与当前授权退出是硬要求。关键条件缺失时，相应路径不开放，不能回落到只验单一 Key。

## 2. 适用边界

项目范围以[需求基线 §2](../requirements/requirements-baseline.md#2-范围边界唯一真源)为准。本契约负责调用者身份、用途、授权、预算、来源、错误、撤权及 C1/C4 的接口与运行约束；不授权新建身份平台或跨域直连外部公网。

## 3. 运行架构与关键机制

- **网关核心拓扑**：基于高性能云原生 API 网关（Kong / Envoy），采用数据面无状态分布式部署与控制面统一配置下发。
- **凭据格式与类型体系**：
  - 个人凭据：`uag-sk-u-` + 43 位以上密码学安全随机字符串（CSPRN），归属具体员工工号。
  - 应用凭据：`uag-sk-a-` + 43 位以上密码学安全随机字符串，归属具体服务与系统代码。
- **双因子凭据协同验证机制（路线 B）**：
  - `Authorization: Bearer <uag-sk-u-...>` 标识长效凭据实体，用于网关拉取限流配额、团队预算及模型路由白名单。
  - `X-IAM-Token: <IAM-JWT>` 携带企业统一 IAM 签发的 RFC 7519 Access Token。
  - 网关基于本地预热的 IAM JWKS 公钥执行微秒级非对称验签，校验签名、有效期与签发主体（Issuer），并严格比对 `jwt.sub == credential.owner_user_id`；比对失败直接阻断。
- **生命周期与五分钟撤权**：
  - 网关监听 IAM 凭证吊销与员工离职/转岗事件，或依赖本地短周期缓存（JWKS 缓存 10 分钟、黑名单广播微秒级推达）。
  - IAM 停用或挂起后，全网节点必须在 ≤ 5 分钟内拒绝一切新请求。
- **流式保活与注释行**：
  - 网关在 SSE 流式传输中每隔 15 秒主动下发 `: ping - <timestamp>\n\n` 保活注释帧，防止企业防火墙/NAT 超时断开；客户端解析器必须容错忽略冒号注释行。

## 4. 契约

本节定义企业级 AI 网关目标契约与能力标准。

### 4.1 身份、用途与凭据

| 项 | 目标契约 | 规范约束 |
|---|---|---|
| 受管个人助手（路线 B） | 必须协同携带 `Authorization` 与 `X-IAM-Token`，通过双因子与人员工号一致校验 | 任一缺失返回 401，工号不匹配返回 403 `iam_token_mismatch` |
| 无人值守 Agent | 使用应用凭据 `uag-sk-a-...`，通过 `Authorization: Bearer ...` 认证 | 校验应用 IP 白名单及系统登记主体，不强制校验 `X-IAM-Token` |
| 客户端 `baseUrl` 解耦 | 客户端配置面板暴露 `baseUrl`，代码统一基于 `${baseUrl}` 相对拼接 | 预设默认值 `https://ai-gateway.corp.example/aig/v1`，严禁硬编码 `/aig/v1` |
| 身份令牌验签 | 基于 IAM `/esc-sso/oidc/jwks` 提供的非对称公钥验证，严格校验 `iss`/`sub`/`exp`/`aud` | 支持 RS256/ES256；时钟容差不超过 ±60 秒；禁用非标准算法 |
| 用途与消费方声明 | 请求头显式携带 `X-Consumer-Type: personal` 与标准 `User-Agent`（包含客户端名称及版本） | 网关对客户端标识执行合法性白名单校验 |
| 凭据自服务与生命周期 | 支持凭据在线申领与自动平滑轮换 | 支持通过自服务端点申领与轮换，轮换期保持新旧凭据 24 小时过渡兼容 |
| 网络边界与来源受限 | 个人访问基于受信任内网/安全办公通道，应用访问严格绑定 IP/CIDR 白名单 | 杜绝任意公网或非授权 IP 接入调用 |

#### 4.1.1 生命周期与失败约束

| 事件 | 必须满足的运行行为 |
|---|---|
| IAM 实际停用 / 网关实际封禁 t0 | 最迟 t0＋5 分钟全网节点拒绝新模型请求，刷新不能延长；状态传播、缓存及容差均计入 |
| 当前客户端退出 | 本地立即停用模型调用、清理安全会话缓存并取消本地在途请求；不牵连其他设备上的有效会话 |
| 服务端接受撤销 t0 | 当前授权及刷新凭据在 ≤ 5 分钟内全网失效，不得用于发起任何新的模型请求 |
| 离线退出 | 本地立即生效，明确提示服务端状态未确认；重新联网后同步撤销状态 |
| IAM 验签依赖不可用 | 若无法验证 IAM 令牌有效性且超出最大安全时钟容差，一律拒绝请求，严禁降级为只验 Key |
| 在途流式传输处置 | 遇到凭据吊销时，已建连流式请求允许按既有超时限制自然终结，后续模型调用立即阻断 |

### 4.2 额度与计量

| 维度 | 键 | 说明 |
|---|---|---|
| 团队 | `team_id` | 团队日/月预算，成本归属唯一真源 |
| 成员 | `owner_user_id` | 成员月度配额与个人限额，同一成员名下多凭据共享同一预算 |
| 凭证 | `credential_id` | 凭据级速率限制（RPM/TPM），防止单端突发流量冲击 |
| 模型 | `model` | 计量与计费细项；支持针对特定高危/大算力模型单独施加策略限制 |
| 窗口 | 日 / 月 / 滑动窗口 | 由网关统一配置与计算，客户端通过标准端点查询当前水位 |

- 计数维度覆盖输入 Tokens、输出 Tokens、推理 Tokens（Reasoning Tokens）及调用次数；费用按照模型基线单价动态核算。
- 网关提供标准配额查询端点 `GET ${baseUrl}/quota`，返回结构包含团队总额、已用额度、重置时间戳及明细列表。

### 4.3 超额与错误映射

网关统一下发标准 RFC 7807 / 统一 JSON 错误格式：

```json
{
  "error": {
    "code": "invalid_iam_token",
    "message": "IAM access token has expired or signature is invalid",
    "type": "authentication_error",
    "param": null
  }
}
```

稳定错误码枚举与客户端处置策略：

| 错误码（error.code） | HTTP 状态码 | 含义 | 客户端处置 |
|---|---|---|---|
| `invalid_api_key` | 401 | 网关长效凭据无效、格式错误或已被删除 | 停止请求，提示用户重新配置或申领凭据；不重试 |
| `invalid_iam_token` | 401 | IAM 令牌过期、验签失败或非法 | 静默尝试触发后台刷新 IAM 令牌并重新发起 1 次；若刷新失败则引导登录 |
| `credential_revoked` | 401 | 网关凭据已被明确吊销或注销 | 立即清除本地持久化密钥，终止企业模型调用 |
| `iam_token_mismatch` | 403 | IAM 令牌所载工号与网关凭据所属工号不一致 | 弹出明确提示，说明身份与凭据归属不符，杜绝转借；不重试 |
| `credential_suspended` | 403 | 凭据处于临时冻结或挂起状态 | 提示联系系统管理员解冻 |
| `model_not_allowed` | 403 | 当前主体未获得指定模型的调用授权 | 提示申请模型访问权限；严禁前端静默偷换其他模型 |
| `client_not_recognized` | 403 | 客户端标识（User-Agent）未在受管白名单内 | 提示升级客户端版本或联系管理员核准客户端标识 |
| `budget_exhausted` | 429 | 团队或个人当期预算用尽 | 解析响应中的 `reset_at` 字段展示重置时间；终止当前调用 |
| `rpm_limit_exceeded` / `tpm_limit_exceeded` | 429 | 触发每分钟请求数或 Token 速率上限 | 读取 `Retry-After` 响应头执行指数退避重试 |
| `gateway_overloaded` / `503` | 503 | 网关过载或底层推理集群排队满载 | 读取 `Retry-After` 实施退避重试；重试上限不超过 3 次 |

### 4.4 服务端点契约与流式协议

网关对外暴露 17 个符合规范的标准端点，核心端点均基于 `${baseUrl}` 相对拼接：

1. **对话与推理**：
   - `POST ${baseUrl}/chat/completions`：标准多轮对话与流式生成（OpenAI 兼容）。
   - `POST ${baseUrl}/responses`：新一代端到端生成式多模态推理端点。
   - `POST ${baseUrl}/messages`：支持 Claude 协议兼容的上下文对话端点。
   - `POST ${baseUrl}/embeddings`：文本向量化计算端点。
   - `POST ${baseUrl}/rerank`：文档精排计算端点。
2. **元数据与生命周期**：
   - `GET ${baseUrl}/models`：动态模型目录查询；响应中为每个模型附带 `capabilities`（模态、流式、上下文长度、最大输出）与 `compliance`（合规等级、部署区域）元数据。
   - `GET ${baseUrl}/quota`：配额与用量实时查询端点。
   - `POST ${baseUrl}/credentials/self-service/issue`：凭据自助申请端点。
   - `POST ${baseUrl}/credentials/self-service/rotate`：凭据自助轮换端点。
3. **SSE 流式心跳规范**：
   - 网关对所有开启 `stream: true` 的长连接按 15 秒周期发送 `: ping - <timestamp>\n\n`。
   - 客户端流式解析器遇到首字符为 `:` 的行必须静默丢弃，严禁作为内容数据进行 JSON 解析。

### 4.5 数据边界与安全审计（C1 / C4）

| 约束项 | 契约要求 |
|---|---|
| 路由边界（C1） | 所有模型路由严禁配置公网商用模型上游；所有推理服务必须部署于机构内隔离算力资源池 |
| 隐私保护与零留存（C4） | 网关对企业个人助手流量默认强制启用 `privacy_mode`，严禁在生产磁盘、集中日志或排障链路中记录请求 Prompt 与响应 Completion 原文 |
| 审计与访问日志 | 审计日志仅记录时间戳、`trace_id`、`request_id`、工号、应用代码、模型名称、Tokens 计量及 HTTP 状态码；日志 WORM 保留期 ≥ 365 天 |
| 排障临时采样 | 严禁生产环境常规抓包采样；因重大故障确需抓包必须经安全合规团队书面特批，并在 7 天内物理销毁 |

## 5. 失败模式与防护

| 场景 | 网关与底层行为 | 客户端应对规范 |
|---|---|---|
| 网关分布式节点缓存延迟 | 凭据吊销广播可能存在微秒级至数秒级同步延迟（上限不超过 5 分钟） | 收到任何 401/403 立即停止重发，不反复重试放大网关压力 |
| 网关限流或瞬时抖动 | 返回 429 或 503，并在 Header 中注入标准 `Retry-After` | 严格遵守 `Retry-After` 退避；未包含则采用 Jitter 指数退避（首重试 ≥ 1.5s） |
| 流式连接意外中断 | 网络链路偶发中断导致长连接未发送 `[DONE]` 终止符 | 检查已接收流式片段长度，提示用户网络异常，允许用户手动点击重试 |
| 离线断网或本地退出 | 本地处于无网络状态或用户触发登出 | 立即销毁内存凭据与在途会话，不得在本地缓存离线明文数据 |

## 6. 验收与对齐标准

- **双因子凭据联动**：实测携带合法 `uag-sk-u-...` 与合法 `X-IAM-Token` 时顺利放行；模拟缺失任一头、令牌篡改或工号不符，网关分别精确返回 401 与 403。
- **`baseUrl` 解耦兼容**：在设置界面将 `baseUrl` 配置为本地抓包代理或企业默认网关地址，流量按预期路由无硬编码阻断。
- **流式心跳稳定容错**：在低速生成与大模型长思考场景下，长连接持续 60 秒以上，15 秒保活心跳行不引起客户端崩溃或报错。
- **五分钟下线硬指标**：在 IAM 触发用户注销或网关吊销凭据后，实测在 5 分钟内所有后续模型调用被网关完全拒止。
