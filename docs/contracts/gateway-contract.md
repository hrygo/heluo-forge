## 1. 结论

网关承担三项职责：将 IAM token 验证为 consumer、按“人 + consumer”双维度记账限额、守住机构内私有化模型的数据与日志边界。DSH 不做本地计量，只负责携带 token、展示 429；两层额度同时生效时取更紧的一侧，错误体通过 `quota_scope` 指明主耗尽层级并通过 `quotas` 数组返回双层快照。网关与模型服务默认不留存请求/响应正文日志。

## 2. 范围与非目标

- 范围：JWT 验签、consumer 映射、额度判定、超额错误、模型目录、请求正文日志与数据边界（C1/C4）。
- 非目标：prompt 计费策略、模型路由算法、上游供应商结算（网关与模型均为机构内私有化部署）。

## 3. 现状与约束

- 网关基于 Kong 自研，与后端模型服务同属机构内私有化部署，无外部第三方模型上游。
- 客户端只持有 IAM access token，不持有网关 API Key。
- 同一 token 可能同时受个人预算（`sub`）与团队/工作负载预算（`consumer`）约束。

## 4. 契约

本节为平台方提出的契约要求，**尚非网关团队已确认能力**；除机构内私有化部署这一用户确认输入外，验签参数、错误字段、统计接口及保留期须由网关/模型服务与安全团队回函，并按 §6 联调后才能冻结。问题域为 `CONF-GW-*` / `CONF-SEC-*`；G0 确认方向、责任与计划并完成主方案要求的 P0 联调，G1 确认接入契约，G2 前冻结生产运行/安全参数。认领或原则支持不代替实测与批准，无回复不视同同意。

### 4.1 身份

| 项 | 要求 |
|---|---|
| 验签 | JWKS 优先；不支持时使用 introspection（RFC 7662）并缓存结果 |
| 算法 | 白名单校验，拒绝 `none` 与对称算法；`kid` 未命中返回 503，不返回 401 |
| claims | `sub` 必填；`aud` 必须包含网关标识；`exp` 与 `iss` 必须验证；时钟容差拟为 60 秒，仅为未确认提议，实际值须由网关/IAM/安全确认 |
| 内省缓存 | 使用 introspection 时单条结果缓存 ≤60 秒，作为撤销延迟上界 |
| consumer | 由 `sub` 或注册信息派生；一人多团队时按显式优先级归属，不在运行时推断 |
| 401 | 仅表示 token 无效或过期；错误体不包含内部细节；自动刷新重试还须满足 §4.3 的未执行/未输出边界 |

### 4.2 额度

| 维度 | 键 | 说明 |
|---|---|---|
| 人 | `sub` | 个人预算，保证公平性 |
| consumer | consumer id | 团队或工作负载预算，保证成本归属 |
| 模型 | `model` | 可按模型设置不同单价或上限 |
| 窗口 | 日 / 月 | 由网关配置，DSH 不假设 |

- 适用额度取所有匹配策略的最小值；任一层耗尽即拒绝。
- 两层同时生效或同时耗尽时，顶层 `quota_scope` 报告更紧的一层（剩余为 0 且重置更晚或优先触发的一侧），同时在 `quotas` 数组中返回两层剩余快照，避免依赖非标响应头。
- 计数单位支持 token、cost、request；具体按模型配置。
- 可选额度查询能力尚未确认提供；`GET /v1/quota` 仅为候选路径示例，不是既有接口。若提供，拟返回各维度剩余与重置时间；缓存不超过 30 秒亦为未确认提议，实际路径、返回契约及缓存时限由网关确认，不据此承诺能力。

**聚合与计量**：网关按主体聚合，不按凭证聚合。

| 项 | 约定 |
|---|---|
| 聚合键 | `(sub, consumer, model, window)`；禁止以令牌值或 `jti` 作为限流与配额键 |
| 刷新影响 | 令牌刷新不清零计数；窗口一律以服务端时间为准 |
| 设备维度 | 客户端携带 `X-Device-Id`（不可逆哈希）；网关记录用于统计与异常检测，不作授权依据 |
| 组织归属 | 由 IAM `groups` 或 SCIM 同步到部门；不在网关运行时推断 |
| 报表字段 | 时间、`sub`、部门、consumer、模型、输入与输出 token、状态、耗时、设备标识 |
| 流式计量 | 在流结束结算；中断或取消按已产生用量计 |

> 若网关需要长期稳定的客户端标识，优先由 IAM 在令牌中增加 `client_instance` claim（待确认），不因此改用长期凭证。

### 4.3 超额错误

```http
HTTP/1.1 429 Too Many Requests
Retry-After: 37
RateLimit-Limit: 1000000
RateLimit-Remaining: 0
RateLimit-Reset: 37
Content-Type: application/problem+json

{
  "type": "https://ai-gateway.corp.example/problems/quota-exceeded",
  "title": "Quota exceeded",
  "status": 429,
  "detail": "Personal daily token quota exhausted",
  "instance": "/v1/chat/completions",
  "quota_scope": "person",
  "quota_limit": 1000000,
  "quota_remaining": 0,
  "quota_reset": "2026-10-21T00:00:00+08:00",
  "quotas": [
    {
      "scope": "person",
      "limit": 1000000,
      "remaining": 0,
      "reset": "2026-10-21T00:00:00+08:00"
    },
    {
      "scope": "consumer",
      "limit": 20000000,
      "remaining": 4520000,
      "reset": "2026-10-21T00:00:00+08:00"
    }
  ]
}
```

| 状态码 | 含义 | 客户端行为 |
|---|---|---|
| 401 | token 无效或过期 | 仅在确认鉴权拒绝、请求未执行且未开始流式输出时，刷新后至多重试一次；仍为 401 则提示重新登录，不无条件重放原请求 |
401 响应宜带 `WWW-Authenticate: Bearer error="invalid_token"`（RFC 6750）；权限不足用 403 与 `error="insufficient_scope"`，避免客户端把授权问题误判为登录失效。
| 403 | 无权限或模型未授权 | 不重试，提示申请权限 |
| 429 | 额度耗尽 | 不自动重试，按 `quota_scope` 与 `quota_reset` 展示恢复时间 |
| 503 | 验签或配额依赖不可用 | 仅确认请求未执行时可退避重试；结果未知时不自动重放 |

**重放边界**：401 本身不证明请求尚未执行。请求已接收、已开始生成、已输出或结果未知时，禁止自动重放；应报告状态并按已确认机制查询/人工核对，不能仅因刷新成功重新提交。上述边界须按 `CONF-GW` 问题域联调验证；网络故障、取消或超时不等于未执行。

### 4.4 模型目录

- 请求的 `model` 必须与网关配置名一致，别名由网关维护。
- 未授权模型返回 403，错误码 `model_not_allowed`，不返回可用模型列表。

### 4.5 数据边界与日志保留（C1 / C4）

| 约束项 | 契约要求 |
|---|---|
| 路由边界（C1） | 所有模型路由仅指向机构内私有化推理服务，禁止配置任何公网或第三方商业模型上游 |
| 正文日志（C4） | 网关与后端模型服务默认关闭请求/响应正文（prompt 与 completion）落盘日志；临时采样须安全审批、最小化脱敏并到期删除。“不超过 7 天”仅为平台方建议上限，未获批准；审批流程、具体保留期与删除证据须在 G2 前冻结，未批准前不得开启采样 |
| 计量与审计日志 | 拟仅记录调用元数据（`timestamp`、`sub`、`consumer`、`model`、`prompt_tokens`、`completion_tokens`、`status`、`latency_ms`）；建议保留 180 天，字段、访问权限和期限待安全/网关确认。按人输出首调用与日活聚合以支撑 M1 / M3 的能力亦待联调，不以采集正文替代该统计 |

## 5. 失败模式

| 场景 | 行为 | 客户端应对 |
|---|---|---|
| JWKS 拉取失败 | 使用缓存密钥；`kid` 未命中时返回 503，不返回 401 | 仅确认未执行时退避重试，不触发登出 |
| 配额存储不可用 | 默认 fail closed（503）；特定环境如需 fail open，须另经有权网关/安全审批，明确环境、范围、期限与风险控制，未经批准不生效 | 仅确认未执行时退避重试；结果未知不自动重放 |
| 计数延迟 | 超额可能延后一个请求生效 | 接受偶发超出，按窗口结算 |
| 时钟偏移 | 容差拟为 60 秒，尚未确认；实际值经确认后冻结，超过已确认容差返回 401 | 校时；如需重试，仍须满足 §4.3 的未执行/未输出边界 |

## 6. 验收

1. 有效 token 调用成功；过期 token 返回 401。
2. 个人额度耗尽返回 429，`quota_scope=person`，带 `Retry-After`。
3. consumer 额度耗尽返回 429，`quota_scope=consumer`。
4. 两层同时耗尽时顶层 `quota_scope` 报告更紧一层，且 `quotas` 数组可读取两层剩余。
5. 未授权模型返回 403，不泄露模型列表。
6. JWKS 轮换后新 `kid` 无需重启即可通过。
7. 默认配置下网关与模型日志不包含用户请求 prompt 正文。
8. 仅在网关确认提供额度查询能力后，验证其返回剩余与重置时间；不以候选路径示例证明接口已存在。
9. 仅可证明鉴权拒绝且未执行、未开始流式输出的 401 允许刷新后至多重试一次；已接收、生成、输出或结果未知的请求不自动重放。
