## 1. 结论

V1 采用 UAG 个人凭证作为模型网关唯一客户端凭据：用户用企业账号（SSO 或目录登录）登录 UAG 控制台，为每台设备创建一把 `uag-` 静态 Key，一次性展示后粘贴进 DSH；客户端以 `Authorization: Bearer uag-…`（或 `apikey: uag-…`）调用。网关用 Kong key-auth 认证，按凭证归属到 `owner_user_id` 与 `team_id`，再执行模型白名单、团队/成员预算、RPM/TPM、路由、计量与审计。客户端不持有上游模型密钥，也不要求 IAM JWT、JWKS 或 introspection。

额度以**团队预算 + 成员预算**落实个人/团队双维度，个人凭证预算作为可选的设备级附加限制；UAG 不提供按模型预算，也不返回 `quota_scope` / `quotas`。预算耗尽返回 `429` 且在 body 给 `reset_at`，RPM/TPM 返回 `429` 并带 `Retry-After`；客户端不自动重试。401 当前不区分缺失、错误、到期、撤销与账号停用，客户端只能引导用户到控制台核查或重建。

C4 的落实依赖逐凭证 `privacy_mode`：UAG 产品默认记录请求/响应正文，河洛使用的每个凭证必须在创建/更换时开启，并由安全抽验。**本文不把“产品默认关闭”写成既成事实。**

## 2. 范围与非目标

- 范围：个人凭证认证、归属、模型白名单、团队/成员预算、RPM/TPM、超额与错误语义、请求正文日志与数据边界（C1/C4）、计量与统计字段。
- 非目标：IAM JWT 验签、JWKS/introspection、客户端自助签发、自动轮换、按模型预算、部门/成本中心模型、MCP 按资源换令牌（V1 不启用 MCP）。

## 3. 现状与约束

- UAG 标准产品基于 Kong；模型路由只认 API Key（`key-auth`），模型路由上没有 `jwt` / `oidc` 插件；只有可选的 AIGS 在 `/mcp` 上验 AAM 签发的 JWT。
- 个人凭证格式为 `uag-` + 32 位十六进制（128 位），无环境标识、无 `kid`；控制面只存不加盐 SHA-256（不参与认证），Kong `keyauth_credentials.key` 存明文。
- 控制台支持 OIDC、LDAP/AD 与本地账号，JIT 建号；IAM 停用需经 SCIM `active=false` 推送，LDAP 只在下次登录控制台时发现，OIDC 无 back-channel。
- 同一凭证可能同时受团队预算、成员预算与可选的个人凭证预算约束；模型只记录、不单独设预算。
- 客户端持有的 Key 为长期凭据，撤销生效受 Kong 节点缓存影响（约 5 秒，漏通知时最长 300 秒）；到期由 60 秒扫描吊销。

## 4. 契约

本节为平台方按 UAG 已知行为提出的接入要求，**尚非网关团队已确认能力**；生产版本、容量、统计接口、错误头与日志策略须由网关/模型服务与安全团队书面确认，并按 §6 联调后冻结。问题域为 `CONF-GW-*` / `CONF-SEC-*`；G0 确认方向、责任与计划，G1 确认接入契约，G2 前冻结生产运行/安全参数。回函、原则支持或代码检索都不代替实测与批准。

### 4.1 身份与凭据

| 项 | 约定 |
|---|---|
| 凭据类型 | UAG 个人凭证，静态 API Key；每台设备一把，名称标注设备 |
| 格式 | `uag-` + 32 位十六进制；无 `kid`、无环境前缀；控制台显示 `uag-****ab12` 提示 |
| 签发 | 用户用企业账号（SSO 或目录登录）进入 UAG 控制台，在 `/personal-credentials` 自助创建；明文仅展示一次；**UAG 不提供客户端签发接口** |
| 请求头 | `Authorization: Bearer uag-…` 或 `apikey: uag-…`，两者择一；`/mcp` 只认 `apikey`，V1 不启用 |
| 认证 | Kong key-auth 查表；模型路由不验 IAM JWT |
| 归属 | 凭证 → `owner_user_id` + `team_id`；客户端自带的 `x-agent-id` / `x-team-id` 等身份头一律清除 |
| 挂起 / 恢复 | 挂起后 `403`，Key 保留；恢复后原 Key 可用 |
| 撤销 / 退役 | 删除 Key，之后 `401`；Kong 节点缓存约 5 秒，漏通知最长 300 秒 |
| 到期 | 60 秒一次的扫描吊销，之后 `401`；有效期可选“永不 / 30 / 90 / 自定义”，无默认与上限，需管理员策略约束 |
| 账号停用 | UAG 内停用/删除即时切断；IAM 停用经 SCIM `active=false` 联动（是否已配置、去重时延待确认）；LDAP 只登录时发现；OIDC 无 back-channel |
| 401 | 表示 Key 缺失、错误、到期、已撤销或账号停用，UAG 当前无法区分；客户端不重试，提示检查 Key 或到控制台核查 |
| 设备维度 | 以凭证名称进入计量；UAG 不采集 `X-Device-Id`，DSH 不再上报设备头 |
| 组织归属 | 只有“团队”一层；部门/成本中心通过“团队按部门建”近似，SCIM 只同步停用/启用，不同步 group |

### 4.2 额度与计量

| 维度 | 键 | 说明 |
|---|---|---|
| 团队 | `team_id` | 团队日/月预算，成本归属 |
| 成员 | `owner_user_id` | 成员月预算，个人公平性；多设备 Key 共享同一预算 |
| 个人凭证 | credential id | 可选的设备级附加限制，不能替代成员预算 |
| Agent / Provider | agent / provider | 服务型 Agent 与供应商上限，非桌面个人场景 |
| 模型 | `model` | 记录到计量；**不设按模型预算** |
| 窗口 | 日 / 月 | 由网关配置，DSH 不假设 |

- 请求只带一把 UAG Key；网关从凭证派生 `owner_user_id` 与 `team_id`，DSH 不传两个身份。
- 聚合键为 `(owner_user_id, team_id, credential, model, window)`；禁止以 Key 值作为限流或配额键。
- 同一成员多设备、换 Key、轮换后预算桶不清零；按此验收，不以“每设备一把”替代个人总量。
- 计数单位支持 token、cost、request；RPM 按凭证所属 Agent 计，TPM 按 `agent_id` 计。
- 流式请求在流结束结算；中断或取消按已产生用量计（具体行为待联调）。
- 额度查询接口未确认；`GET /v1/quota` 不是既有接口，V1 不承诺。

### 4.3 超额与错误

预算耗尽示例（UAG 当前格式）：

```http
HTTP/1.1 429 Too Many Requests
Content-Type: application/json

{"error":"budget_exhausted","reset_at":"2026-10-23T00:00:00+08:00"}
```

RPM/TPM 超限返回 `429`，带 `Retry-After`。预算 429 不带 `Retry-After`，也不使用 `application/problem+json`、`quota_scope` 或 `quotas` 数组。

| 返回 | 含义 | 客户端行为 | 可自动重试 |
|---|---|---|---|
| `401 Unauthorized` / `No API key found in request` | Key 缺失、错误、到期、撤销或账号停用（当前无法区分） | 提示检查 Key 完整性，并到 UAG 控制台查看该凭证状态或重建；不重试 | 否 |
| `403 You cannot consume this service` | 凭证被挂起 | 提示联系团队管理员；恢复后原 Key 可用 | 否 |
| `403 POLICY_DENIED` / `PENDING_APPROVAL` | 策略拒绝 / 需要审批 | 展示原因；待审批的提示到控制台跟进 | 否 |
| `400 MODEL_NOT_ALLOWED` / `MODEL_NOT_ROUTABLE` / `MODEL_REQUIRED` | 模型未授权、不可路由或未填 | 提示申请模型权限或检查模型名；不静默换模型 | 否 |
| `422 NO_ROUTE_STRATEGY` | 该凭证没有配置路由策略 | 提示联系管理员 | 否 |
| `429 {"error":"budget_exhausted","reset_at":…}` | 团队 / 成员 / 凭证预算耗尽 | 展示 `reset_at`；无法区分层级时提示到控制台查看；不重试 | 否 |
| `429 RPM_LIMIT_EXCEEDED` / `TPM_LIMIT_EXCEEDED` | 每分钟请求数 / token 数超限 | 按 `Retry-After` 退避 | 按 `Retry-After` |
| `5xx` / 超时 | 网关已在内部重试和容灾，结果未知 | 不盲目重放；已经输出过内容的请求不重放 | 否 |

**重放边界**：401 本身不证明请求尚未执行；请求已接收、已开始生成、已输出或结果未知时，禁止自动重放；应报告状态并按已确认机制查询/人工核对。网络故障、取消或超时不等于未执行。UAG 内部对 429/5xx 的重试可能重复生成或计费，客户端不得再用自动重放放大。

### 4.4 模型目录

- 模型授权以 UAG 凭证级“允许的模型”为准；DSH 的 `gateway.models` 是客户端白名单，必须是凭证允许集合的子集。
- 未授权模型返回 `400 MODEL_NOT_ALLOWED`，不返回可用模型列表；DSH 不静默降级到其他模型。
- UAG 是否提供模型目录接口未确认；V1 以配置白名单 + 控制台授权为准。

### 4.5 数据边界与日志保留（C1 / C4）

| 约束项 | 契约要求 |
|---|---|
| 路由边界（C1） | 所有模型路由仅指向机构内私有化推理服务，禁止配置任何公网或第三方商业模型上游 |
| 正文日志（C4） | UAG 产品默认记录请求/响应正文，`privacy_mode` 可按凭证关闭；河洛使用的每个个人凭证必须在创建、更换、轮换时开启 `privacy_mode`，并由平台组核对、安全抽验网关与模型日志不含 prompt/completion。逐凭证开关不是产品默认值，需以开通/运行控制补足 |
| 计量与审计日志 | 分析稿称 UAG 记录 `owner_user_id`、`team_id`、agent/凭证、provider、model、token、成本、状态、耗时、trace；审计保留 ≥365 天、WORM + HMAC 链，均待核验。DSH 只上报调用元数据，不报正文 |
| 排障采样 | 任何正文采样仍须安全审批、最小化脱敏并到期删除；“不超过 7 天”仅为平台方建议上限，未获批准不得开启 |

## 5. 失败模式

| 场景 | 行为 | 客户端应对 |
|---|---|---|
| Kong 缓存未失效 | 撤销/挂起后短时间内旧 Key 仍可能通过（约 5 秒，最长 300 秒） | 不把一次 401/403 当全网生效；按控制台状态与重试提示处置 |
| 预算存储不可用 | UAG 行为待确认；不得假定 fail open | 仅确认未执行时退避；结果未知不自动重放 |
| 计数延迟 | 超额可能延后一个请求生效 | 接受偶发超出，按窗口结算 |
| SCIM 未接通 | IAM 停用不会自动切断已有 Key；LDAP 只在登录时发现 | 以离职工单触发 UAG 停用/批量撤销，TTL 兜底；G2 前验证 |
| Kong 库泄露 | 明文 Key 可被直接使用 | 依赖 DB/备份访问控制、静态加密评估、审计与批量撤销；安全书面接受 |
| Key 共用/转借 | 计量与审计都归到 Key 的 `owner_user_id`，无法区分实际使用者；客户端 `ownerSubject` 绑定只阻止账号切换，不阻止手工外借 | 明确禁止共用；异常用量按 owner 追责；不把凭证名当作使用者身份 |
| 控制台不可用 | 已签发 Key 仍可用；新用户/轮换受阻 | 提示稍后重试；不共用他人 Key |

## 6. 验收

1. 一把真实 UAG 个人凭证分别以 `Authorization: Bearer` 与 `apikey` 完成一次模型调用。
2. 缺失、错误、到期或撤销的 Key 返回 401；客户端不自动重试，能引导到控制台核查/重建。
3. 挂起返回 403；恢复后原 Key 可用。
4. 预算耗尽返回 429，body 含 `reset_at`；RPM/TPM 429 带 `Retry-After`；客户端展示对应恢复信息。
5. 未授权模型返回 400，不泄露模型列表，不静默换模型。
6. 河洛凭证开启 `privacy_mode` 后，网关与模型日志不含请求/响应正文；抽验记录留档。
7. IAM 停用经 SCIM 或经确认的离职工单在约定窗口内切断该用户全部凭证。
8. 同一成员两把设备 Key 共享成员预算；更换 Key 或轮换后预算不清零。
9. 网关可按人去重输出首调用与日/周活跃数据，或书面说明不可用及替代口径（M1/M2/M3 依赖）。
10. 流式取消、超时与 5xx 的结果未知边界实测；已输出内容不自动重放。
11. 生产/试点 UAG 版本、并发、吞吐、时延、最大超时与 SLA 取得书面数据；未取得不通过容量门禁。
12. `owner_user_id` 与 IAM `sub` 的映射/去重口径有书面说明；审计与统计可按该键核对。
