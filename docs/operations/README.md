## 1. 结论

本目录承载双端分发、私有市场发布、回滚与支持的运行手册。G2 前必须完成，当前只有索引与边界说明，没有可执行手册或已演练的恢复流程。

市场插件与 HTTP 参考服务已有本地用法和测试，分别见[插件说明](../../packages/forge-market/README.md)与[服务说明](../../services/market-index/README.md)。这些开发验证步骤不等于生产运行手册；参考服务的目录、评审和审计仍为内存态，下载计数文件也不构成业务备份与恢复方案。
