## 1. 怎么判

- **必过项**全部通过 → 本轮验收通过。
- 必过项有一项不通过 → 记录现象，连同第 5 节的反馈信息一起交回。
- **观察项**只记录实际看到什么，过与不过都写下来。

## 2. 必过项

| 编号 | 要做什么 | 应该看到什么 |
|---|---|---|
| U-01 | 按[安装与启动](<安装与启动.md>)第 1–5 步装好并启动 | 打印出带 `?token=` 的链接；除预期的 `1 entry did not activate` 外没有别的报错 |
| U-02 | 用该链接打开页面 → 点左下角齿轮「设置」 | 左侧有 7 项：通用设置、内置插件、Agent 预设、**企业研发**、**企业账号**、**Gitee**、**DevOps**；没有「模型」 |
| U-03 | 点「企业研发」 | 顶部摘要 `⚠ N 项待处理 · 先处理身份与 Key`；两行：`身份与 Key`（未登录 · 无法判定）、`本机工具`（已配置 · dop 已找到 · Gitee 未配置）；底部一句 `本页只显示本机可见性，不代表业务授权…` |
| U-04 | 在「企业研发」点「身份与 Key」右侧「详情」 | 出现 `公共参数：企业分发，本机不可改`、`身份与 Key / 未登录`、`网关 Key / 未知 / 无法判定`、`前往企业账号登录 · 设置 → 企业账号` |
| U-05 | 在「企业研发」点「检查 DevOps」 | 几秒内出现 `检查：通过 · 时间`；展开「本机工具 / 详情」可见 `基准`、`检查时间`、`对象`、`来源类型 本地诊断`，以及四项证据（文件存在 / 可启动 / 目标可识别 / 配置形状）各带依据 |
| U-06 | 点「Gitee」 | 标题 `Gitee`；一句 `公共参数由企业分发；这一页只改本机差异。`；状态 `全部沿用公共值与默认值`；三行：命令行入口（已自动找到 gh）、命令超时、服务地址与凭据（由企业分发，本页只读）；有 `高级 · 通常不用改` |
| U-07 | 点「DevOps」 | 标题 `DevOps`；`dop 已自动找到`；`dop 可执行文件` 与 `命令超时` 两行；最下面 `检查` `保存` 两个按钮，未改动时 `保存` 是灰的 |
| U-08 | 点「企业账号」 | 一句 `登录只建立身份，不代表已获得业务写权限。`；三个步骤：身份（待配置登录）、凭据（待配置）、模型（待解锁）；问题一条 `企业登录设置不完整，请联系管理员。`；有 `刷新`、`登录后可配置`、`诊断` |
| U-09 | 整轮操作期间观察终端与浏览器控制台 | 除启动时那条 `1 entry did not activate` 和页面明确写出的提示外，没有其它红色报错 |
| U-10 | 验收结束，按[安装与启动](<安装与启动.md>)第 4 节收工 | 服务能停掉；删掉 `~/dsh-uat` 后，日常 DSH 打开一切照旧 |

## 3. 观察项

| 编号 | 要做什么 | 记录什么 |
|---|---|---|
| O-01 | 「企业研发」里点「检查 Gitee」 | 本轮未配置 Gitee 检查通道，按钮应是禁用或给出"%未获批准%"。记录实际提示原文 |
| O-02 | 「Gitee」点「手动指定」 | 是否出现输入框；再点「恢复自动发现」是否回到 `已自动找到 gh` |
| O-03 | 「DevOps」把命令超时改成 `30000` 后点「保存」 | 出现一句回执。没有企业端点时会显示 `已保存 · 未生效（命令面未按新配置重建，请检查企业端点与命令行入口）`——这是本轮无参数环境的预期，不是缺陷；只要**不出现** `CLI_` 之类的原因码即可 |
| O-04 | 「DevOps」把命令超时改成 `30` 后点「保存」 | 提示 `请输入 1000–600000 之间的整数（毫秒）`，且不写入（回执为 `未保存`） |
| O-05 | 「企业账号」点「诊断」→「复制登录链接」 | 是否出现"已复制"之类的可见提示；剪贴板里是否是链接 |
| O-06 | 页面文字观感 | 有没有露出英文键名（例如 `readiness.`、`field.`）、乱码、被截断的句子 |
| O-07 | 重启一次服务再打开新链接 | 页面是否正常加载、之前保存过的值是否还在 |

## 4. 本轮不验

真实企业登录与网关 Key、真实 dop/gh 命令执行与企业端点请求、Windows/麒麟安装包与双端一致性、多人并发保存、企业侧权限判定。以上不通过不构成本轮不通过。

## 5. 反馈要带什么

- `dsh --version`。
- 启动那一步终端最后 20 行。
- 出问题页面的截图，或可见文字。
- 复现步骤：第几步、点了什么、期望看到什么、实际看到什么。

不要附 token 链接、账号、密钥、内网地址。
