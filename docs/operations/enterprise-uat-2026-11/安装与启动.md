## 1. 开始前

- 这台机器已经装好 `dsh`，并且能打开本机浏览器。
- 安装包三个文件放在同一个目录，例如 `~/下载/企业插件包/`。
- 全程用一个**新的**配置目录（下面叫 `~/dsh-uat`），不要指向日常在用的配置。

## 2. 六步

每一步都给了"看到什么算成功"。没看到预期结果就先别往下走。

### 第 1 步：确认版本

```sh
dsh --version
```

算成功：打印一个 `0.2.x` 的版本号，且不低于 `0.2.1-rc.2`。

### 第 2 步：指定临时配置目录

macOS / Linux：

```sh
export DSH_HOME=~/dsh-uat
```

Windows PowerShell：

```powershell
$env:DSH_HOME = "$HOME\dsh-uat"
```

算成功：`echo $DSH_HOME`（PowerShell 用 `echo $env:DSH_HOME`）显示你刚设的路径。

> 这个变量只管当前终端窗口。**后面每一步都要在同一个窗口里做**，关掉窗口就要重设。

### 第 3 步：建一份空的配置模板

```sh
dsh --profile uat --from-default-profile web --dump-config
```

算成功：命令正常结束、没有报错（它只建模板，不启动界面）。

### 第 4 步：装插件包

先把安装包路径换成你自己的**绝对路径**（不要用相对路径）：

```sh
dsh plugin --profile uat add /绝对/路径/heluo-forge-enterprise-0.1.0.tgz
```

算成功：输出里有 `+ @heluo/forge-enterprise 0.1.0`，以及一行类似 `Progress: resolved ... added 1 package`。看到 `ENOENT` 说明路径写错了或用了相对路径。

### 第 5 步：启动

```sh
dsh --profile uat --host 127.0.0.1 --port 48494 --no-open
```

算成功：最后打印这样一行，复制整行（带 token）：

```
dsh web: http://127.0.0.1:48494/?token=xxxxxxxx
```

启动时可能出现两行提示，都属正常，不影响验收：

```
dsh: warning: 1 entry did not activate
account-controller (@deepseek-ai/dsh-api-account-controller): pending (waiting for service: deepseekAccount)
```

原因：企业包为了不暴露个人账号体系，关掉了内置账号控制器；它等不到依赖，所以显示 pending。**这个窗口不要关**，关了服务就停了。

### 第 6 步：打开页面

把第 5 步打印的完整链接（含 `?token=`）粘到浏览器地址栏。

算成功：

- 看到 DSH 主界面，左下角显示「企业账号 · 企业账号未登录」。
- 点左下角齿轮「设置」，左侧列表有 7 项：通用设置、内置插件、Agent 预设、企业研发、企业账号、Gitee、DevOps。
- 没有「模型」这一项，是企业包的预期设计（模型走企业网关，不在设置里选）。

## 3. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 打开链接显示 `authentication required` 或 401 | 链接里的 token 过期了（每次重启都会换）。回到第 5 步的终端，复制最新打印的那行链接 |
| 启动后没有任何输出，也不打印链接 | 第 3 步没做，profile 是空的。先执行第 3 步再启动 |
| 报 `too many arguments ... got 1: web` | 启动命令末尾多写了 `web`。按第 5 步原样执行 |
| `dsh: command not found` | DSH 没装或不在 PATH 里，先解决 DSH 安装 |
| 设置里只有通用设置等原生项，没有企业页 | 装到了别的 profile。确认第 4、5 步都用 `--profile uat`，且 `DSH_HOME` 是同一个 |
| 页面提示「企业登录尚未设置」 | 预期结果。本轮没有配企业参数，见验收清单 U-08 |

## 4. 收工

验收做完后：

1. 在第 5 步的终端按 `Ctrl+C` 停掉服务。
2. 删除临时配置目录：`rm -rf ~/dsh-uat`（PowerShell：`Remove-Item -Recurse -Force "$HOME\dsh-uat"`）。
3. 重新打开日常的 DSH，确认一切照旧。
