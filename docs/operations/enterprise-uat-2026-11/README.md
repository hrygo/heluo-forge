## 1. 这是什么

一个插件压缩包，装到一个**单独的** DSH 配置目录里，用来验证企业研发相关的四个设置页能不能正常装、正常用。

装完你会有：设置里多出「企业研发」「企业账号」「Gitee」「DevOps」四个页面。这一轮只验收"装得上、看得见、显示对、按钮行为合理"，**不验收真实企业登录**（没有企业参数，登录页会提示"企业登录尚未设置"，这是正常的）。

## 2. 包里有什么

| 文件 | 用途 |
|---|---|
| `heluo-forge-enterprise-0.1.0.tgz` | 插件包本体，装在 DSH 里 |
| `SHA256SUMS` | 校验值，用来确认文件没传坏 |
| `bundle-manifest.json` | 包内清单：包含哪几个插件、每层文件的校验值 |

校验方法（在文件所在目录执行）：

```sh
shasum -a 256 -c SHA256SUMS
```

看到两行 `OK` 即可。Windows 上可用 `certutil -hashfile heluo-forge-enterprise-0.1.0.tgz SHA256` 与 `SHA256SUMS` 里的值对照。

## 4. 这轮验什么、不验什么

验：

- 插件包能在内网机器上装上、启动不自崩。
- 四个企业设置页出现，文字与状态显示正常、没有乱码或英文键名。
- 「检查」「保存」「刷新」按钮点了有合理反馈。
- 删掉临时配置目录就能干净回滚，不影响日常使用的 DSH。

不验（本轮范围外，不要因为这几项没过就判不通过）：

- 真实企业登录、真实网关 Key、真实 dop/gh 调用。
- Windows/麒麟安装包（MSI/deb）、双端一致性。
- 企业侧权限、并发保存、多人协作。
- 真实数据的读写与提交。

## 5. 出问题怎么反馈

请一起提供：

- `dsh --version` 的输出。
- 启动那一步的最后 20 行输出（终端里的）。
- 出问题的页面截图，或把设置页里可见的文字贴过来。
- 复现步骤（第几步、点了什么）。

**不要**把 token 链接、账号、密钥、内网地址贴进反馈里。

## 6. 回滚

本轮所有内容都装在你新建的临时配置目录里。回滚就是删掉它：

```sh
rm -rf ~/dsh-uat
```

删完日常使用的 DSH 不受影响。确认方法见[验收测试清单](<验收测试清单.md>)最后一条。
