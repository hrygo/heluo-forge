## 使用说明

- Markdown 文档可直接在 IDE 中预览、搜索和关联到主计划；Excel 仅用于逐项筛选与审查底稿。
- 目录按主题组织，不按年份；版本在文档信息中维护，不进入目录名或文件名。
- 主计划更新时，先改 `../rollout-plan.md`，再同步本目录中的快照与配套材料。
- 本目录不新增受控文档编号；对外引用以主计划的 `CORP-DSH-PLAN-001` 为准。
