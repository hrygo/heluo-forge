## 1. 怎么用

1. 每项指定责任人，留下 URL、命令输出、截图或回执。
2. 状态只写“通过 / 部分 / 未取 / 不成立”，并写核验日期与执行人。
3. 关键项（M1、M2、M3、M5）任一不成立，市场保持不可用，不宣称轻量模式可上线。

## 3. 本仓库已能自证的部分

- **format-1 解析行为**：2026-10-21 只读核对 DSH `0.2.1-rc.2` 的索引解析器；`title.en`、版本降序、npm source、icon 限制与未知成员丢弃已确认。
- **校验工具**：`services/market-index/validate-index.mjs` 可校验 URL 或本地文件；本地相对 icon 需 `--base`。
- **无生成器/服务**：仓库不再包含市场服务、生成器、发布器或 `current/policy/evidence`；目标链路只依赖 AIHUB 索引 + 原生市场 + Artifactory。
- **无企业实机证据**：尚未用 AIHUB 真实索引或企业 Artifactory 完成任何安装。

## 4. 关闭条件

- M1～M7 全部“通过”，并附三目标安装记录与撤回回执，才可关闭 P0。
- M8 若结论为“不接受 HTTP 索引”，M1 必须改为 HTTPS URL。
- 任一关键项不成立：记录“不可用决议”，不把索引加入终端，不宣称市场已上线。
- 关闭不等于 AIHUB 内部审批完成；本单只验证“索引可被原生市场安全消费”。

## 5. 与旧治理模式的关系

旧的生成器、`current/policy/evidence`、CI 单写、15 分钟租约与写前授权不再属于本方案，也不再作为 P0 项。其历史记录见 Git 历史与 [DESIGN-007 附录 A](<../design/plugins/forge-market.md>)；不要用旧检查表判断当前进度。
