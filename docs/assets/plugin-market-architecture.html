企业插件市场：轻量原生索引架构

不建市场服务、不建生成器、不做写前授权。AIHUB 给目录，DSH 原生市场给入口，Artifactory 给包体；本项目只定义索引契约、提供只读校验并做三目标验收。

01它是什么

目录

AI 开发者平台（AIHUB）维护并托管一份 format-1 索引 JSON，提供稳定只读 URL。

入口

DSH 原生「插件市场 → 索引源」；用户添加 URL 后浏览插件与精确版本。

安装

官方 pluginManager + pnpm，从索引指定的企业 Artifactory 拉取 tarball。

本项目

索引契约、只读校验器、P0 取证与三目标验收；不生成、不托管、不代理。

一句话：索引只回答“有哪些包、哪些精确版本、从哪个 npm 源装”，不回答“现在是否允许装”。

02一条主链路

1
AIHUB 产出索引format-1 JSON：插件、精确稳定版本、npm source、图标与说明。
2
用户添加索引源原生市场 → 索引源 → 粘贴 AIHUB 只读 URL；原生提示第三方来源风险。
3
浏览并选择版本市场展示索引内容；只安装索引中列出的 name@version。
4
官方 manager 安装pnpm 从 source.registry 取包；企业 ACL、同版不可变由 Artifactory 执行。
5
更新或撤回AIHUB 更新 JSON；撤回删版本并在私服阻断。已装代码不自动卸载。

03AIHUB 交付什么

交付物要求
索引 URL稳定、只读、无凭据；优先 HTTPS，内网 HTTP 可接受；不重定向；Content-Type: application/json。
JSONformat: 1；title.en 必填；版本精确、稳定、去重、降序；source.type 只允许 npm。
registrysource.registry 指向企业 Artifactory；索引不含 token；终端通过 .npmrc 读包。
更新时限新版本 ≤10 分钟；撤回 ≤5 分钟；生成失败保留上一份完整 JSON。
联调三目标各装一次同一精确版本；删除版本后市场不再显示；错误 JSON 不被展示。
负责人索引更新、撤回、值班联系人与故障升级路径。

完整字段、示例与待确认问题见 issue #12 与 DESIGN-012。

04不能保证什么

没有写前授权

索引可读即可安装；没有 installEnabled、租约或每次写前复核。

没有逐版本证据

format-1 没有 integrity、OS/CPU、matrix 或 policyRevision；只能依赖 AIHUB 策展与私服不可变。

不能覆盖全通道

用户仍可添加其它索引、用 CLI 或任意 spec 安装；不宣称 REQ-14/G2 全通道通过。

不能远程卸载

删索引只停止新的目录安装；已装代码需终端运维独立处置。

安全边界：安装信任来自 AIHUB 策展、Artifactory ACL/同版不可变、原生市场提示与终端网络边界；不来自本仓库的生成器或授权服务。

05验收：能加、能看、能装、能撤

项通过标准
能加三目标各一台，在原生「索引源」添加 AIHUB URL，无报错。
能看市场显示索引中的插件、版本、说明与图标。
能装三目标各安装同一精确版本成功，包来自企业 Artifactory。
能撤删除版本后刷新不再显示，且无法再安装该版本。
错误输入缺 title.en、版本重复、source.type: git 被拒绝或明确报错。
断网索引不可达时市场不崩溃；恢复后可重新加载。
