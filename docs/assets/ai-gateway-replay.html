1结论

UAG 标准产品今天的客户端接入形态，属于方案 B（静态 Key）这一族，叫「个人凭证」。签发、展示一次、按人归属、挂起与吊销、预算与限流都已具备。方案 A（令牌直通）在 UAG 数据面目前不支持：模型路由只认 API Key，不验 IAM 签发的 JWT。
  • 能直接用的：
    • 控制台用企业 OIDC 或 LDAP 登录，首次登录自动建号（JIT）。
    • 用户自助签发个人凭证，明文只展示一次。
    • 按团队、成员、凭证、Agent 设预算，另有 RPM / TPM 限流。
    • 流式请求在流结束时计量，可导出按团队分摊的报表。
    • 上游模型密钥对客户端不可见。
    • 用户被停用或删除时，名下凭证在网关侧同步切断。
  • 与方案 B 的主要差距：
    • 轮换没有新旧并存期。
    • 有效期没有默认值和上限，也没有到期提醒。
    • 401 不区分「到期 / 已撤销 / 账号停用」。
    • 没有设备维度（X-Device-Id）。
    • 没有部门 / 成本中心。
    • LDAP 停用账号不会主动联动网关，要靠 SCIM。
    • Kong 库里的 Key 是明文。
  • 要支持方案 A，需要新增数据面 JWT 验签：iss / aud / exp / kid、JWKS 缓存，以及 sub→用户、consumer 的映射。这是一项独立能力，不属于小改，建议作为可选接入模式单独规划。

2三者定位

方案 A · 令牌直通

客户端只持 IAM 的 refresh / access token，Bearer <IAM token> 直调网关。网关负责验签，并从 sub 派生出 consumer。

MCP 按 resource 单独取令牌，服务端校验 aud。

UAG 数据面不支持

方案 B · 静态 Key

用户在网关控制台通过 IAM 登录后，自签长期 Key（csk_<env>_<kid>_<secret>），每台设备一把，粘贴进 DSH。

网关按 kid 查表校验，存的是 HMAC。

UAG 已覆盖主体，细节有差距

UAG 标准 · 个人凭证

用户用企业 SSO 登录 UAG 控制台，自助创建个人凭证（uag- 加 32 位十六进制）并绑定团队。客户端用 Authorization: Bearer uag-…（兼容 OpenAI SDK）或 apikey 头调用。

网关经 Kong key-auth 认证后，归属到人和团队，再计预算与限流。

现网可用

3UAG 标准接入方案（按现有能力）

一句话：人用企业 SSO 登录 UAG 控制台，每台设备自助签一把个人凭证；客户端只持这把 UAG Key，用 Authorization: Bearer 调网关；身份、额度、模型边界、计量全部由网关从凭证派生。客户端不持上游模型密钥，也不持 IAM 令牌。

7统计、额度与 FinOps

关注点UAG 现状对河洛的建议
聚合键每次请求都记录 owner_user_id、team_id、agent / 凭证、provider、model、各类 token、成本、状态、耗时、trace_id等价于方案里的 (sub, consumer, model, window)，可直接对齐
限流桶RPM 按 consumer（即凭证所属 Agent），TPM 按 agent_id，不按 Key 值每人一把个人凭证 ⇒ 天然按人限流；轮换后桶不清零
预算团队月 / 日、成员月、个人凭证月、Provider；无按模型预算团队月预算 + 个人凭证月预算两层即可覆盖「双维度」
设备凭证名称进入计量；无设备头名称统一用设备标签
部门分摊只有团队；导出按团队分摊团队按部门建
正文日志默认记录，可按凭证开 privacy_mode河洛若要求「只记元数据」，给河洛用户的凭证统一开 privacy_mode

8工具调用（MCP）

  • 入口：客户端用同一把 UAG Key 调 /mcp 或 /mcp/<hub>（Streamable HTTP），用 apikey 头，目前不认 Bearer。
  • 门禁：平台按工具授权：call、call_with_approval、view_only。决策结果为 allow、deny、pending_approval，并有审批单和风险等级。
  • 上游凭据：由网关持有，加密存储，客户端看不到。支持 none、api_key、bearer、oauth2 client_credentials 四种。client_credentials 请求不带 scope 和 audience。
  • 按资源取令牌（对应方案 A 的 resource / aud）：只在启用 AIGS / AAM 时有，走 RFC 8693 token-exchange，aud = mcpID:toolName。标准部署默认不启用。
