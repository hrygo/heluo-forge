在各大生图平台（Midjourney、DALL-E 3、Flux.1、SDXL）中使用本套提示词时，请保持以下核心约束：

* **色彩系统**：
  * 主渐变：皇家深蓝 (`#1D4ED8`) → 电光钴蓝 (`#2563EB`) → 极光青 (`#00D2FE`) → 赛博霓虹青 (`#00F5FF`)
  * 背景底色：纯净暗黑曜石深蓝黑 (`#070C16` 或 `#0B1224`)
* **构图比例**：`1:1` 方形画幅（App Icon 标准比例，主体居中，四周留出约 15%~20% 呼吸净空）
* **艺术风格**：`DeepSeek iconic minimalist vector logo style, single fluid aerodynamic curves, G2 curvature continuity, Apple Design Award quality, ultra-clean vector emblem`
* **通用负向提示词 (Negative Prompt)**：
  `text, words, letters, typography, watermark, signature, realistic wrinkles, scales, traditional dragon whiskers, claws, ferocious face, horns overload, 3D render noise, photorealistic skin, low poly, origami, messy lines, frame, border`
