配色与使用

保留象首识别，大幅区分组件形态

平台靛蓝#293CCF
推理青#16AEC0
文字深墨#10192D
深色底#111D42
  • 浅底使用彩色或深墨版本；深底使用反白版本。保留象首宽度 1/8 以上净空。
  • 主图标建议 ≥32px；组件图标建议 ≥64px。较小位置使用主图标与周围组件文字。
  • 正常尺寸保留“企业级智能研发平台”；狭窄位置使用主图标或纯字标。
  • 所有 SVG 字标已转曲；PNG 从同一矢量母稿导出。应用图标自带深色背板。
  • 组件标识描述职责，不表示相应功能已实现、已部署或已批准。
