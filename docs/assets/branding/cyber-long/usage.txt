一、品牌含义与视觉基因
1. 渊源：“河出图，洛出书，圣人则之”。黄河奔涌，神龙负图而出，奠定华夏数理哲学源头。
2. 现代：“潜龙在渊，腾跃九霄”。以单笔 G2 连续流体曲率塑造神龙飞腾姿态，线条纯粹克制。
3. 族谱规范：全库 11 个子组件保持螭龙飞腾轮廓核心，依组件业务语义演变有机动态与环抱徽记，兼顾统一品牌心智与极简矢量化。
4. 色彩：深邃暗黑 (#070C16) + 皇家电光蓝 (#1D4ED8 -> #2563EB) 至极光青 (#00D2FE -> #00F5FF) 的平滑漫射。
