一、品牌含义与视觉基因
1. 渊源：“河出图，洛出书，圣人则之”。黄河奔涌，神龙负图而出，奠定了华夏数理与易经二进制哲学源头。
2. 现代：“潜龙在渊，腾跃九霄”。以单笔 G2 连续流体曲率重塑神龙飞腾，彻底摒弃传统龙爪须发的琐碎。
3. 族谱规范：全库 11 个子组件完全保持螭龙飞腾轮廓不变，于龙心环抱处融合功能语义徽记，兼顾统一品牌心智与极简矢量化。
4. 色彩：深邃暗黑 (#070C16) + 皇家电光蓝 (#1D4ED8 -> #2563EB) 至极光青 (#00D2FE -> #00F5FF) 的平滑漫射。
