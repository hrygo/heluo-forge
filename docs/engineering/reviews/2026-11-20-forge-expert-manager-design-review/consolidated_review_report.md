# 专家智能体管理插件独立设计评审

> 2026-11-20 · Agent 代拟 · EGM 五阶段独立评审。审查 V0.5.0 全文共 247 行，设计部分为 1–184 行，实施计划为 185–247 行。修订落入 [V0.6.0 详细设计](../../../design/plugins/forge-experts.md)。

V0.5.0 的主要缺口是管理与真实委派的门禁混杂、写入及失效存在未定义的时序、目标发行物取证依赖尚未创建的插件。V0.6.0 给出分阶段开放条件、偏好与发送的生效边界，以及建包前的独立安装探针。员工仍在原生设置页手动启停专家，默认未启用。实施跟踪沿用 [#246](https://github.com/hrygo/heluo-forge/issues/246)。
