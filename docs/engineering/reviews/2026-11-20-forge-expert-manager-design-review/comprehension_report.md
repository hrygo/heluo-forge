# What this proposes

`@heluo/forge-experts` 让员工在设置页查看目录并手动启停专家。聊天候选只包含当前会话范围内可调用、可接单且个人已启用的专家。DSH Host 按实例、组织和员工身份保存偏好，身份、委派范围、权限或接单状态变化时更新旧候选及待提交选择。真实委派等待可信选择、员工授权和 Delegra 受限受理通过验收。按 §3.6–3.7，管理能力具备独立交付路径。

## How the existing system works, per this document

Delegra 管理目录、权限、接单状态和任务生命周期。方案中 DSH Host 提供同源路由、持久化个人偏好，按当前身份和范围形成候选。固定版本源码提供设置槽、候选源、存储域和目录的接入依据。目标发行物装配、员工授权目录和真实提交仍待实测。选择失效时方案保留草稿，候选资格无法确认时暂停候选，保存结果未知时回读或暂停相关存储域。

## 可理解性发现

**C1 · 重要。** §3.1、§3.2、§3.6 和 §5.1 要求复用 `Policy`，读者无法仅凭文档确定该宿主服务在实际出站时判定哪些动作、何处拒绝，以及与 Delegra 的服务端授权如何分工。应在首次提及时定义 Forge Policy，明确 Host 出站门禁和服务端受理的职责，并引用相关接入约束。
