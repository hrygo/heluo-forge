# 专家智能体管理插件实施就绪度评审

> 2026-11-20 · Agent 代拟 · EGM 阶段 9 · 独立审查 V0.5.0 第 5 节

现有通用探针可复跑固定 SDK 基线。管理包的目标宿主、员工接口和独立制品取证仍待完成。实施就绪、生产候选、真实委派分别以各自验收结果为准。

| 编号 | 严重度 | 发现及预期修订 |
| --- | --- | --- |
| R1 | 阻断 | 建包前置要求有装配和存储闭包证据，但唯一专项入口在未来包内。使用包外隔离脚本构建临时独立 tarball 并在目标终端装入。真实发行物须证明公开导出和 schema 的解析、存储域开启、写入、重启回读及单 Host 写入 |
| R2 | 阻断 | 管理包的配置默认值、装配、独立制品输入和安装入口未固定。取证结束后冻结已验依赖、导出、默认关闭的配置和关闭路径。`check:tarballs` 校验包体，现有 SDK 探针和组合排演提供参照。UI 验收走实际 Electron 或 Web 入口，必要项阻塞或跳过保留待验 |
| R3 | 阻断 | 实施清单缺少实际 Host 工具发送和未知受理的文件与责任。将选择绑定和出站执行分配到具体文件，按 #245 冻结实际接缝，由 #247 提供唯一的持久请求关联及受权回查，Delegra 权威受理必须可对账 |
| R4 | 重要 | §5 需区分管理准入、候选隔离取证与真实委派，指定新建、更新文件及责任。在候选取证阶段保持生产点选关闭 |
| R5 | 重要 | 固定 DSH 注销能撤下旧组，文件或会话组保持打开时重注册不会补回专家组。验证旧组移除、其他组保留、菜单重开后恢复当前候选 |
| R6 | 重要 | 原生 `table.put` 无记录 schema 校验，POSIX `rename` 后仍可能发生耐久确认失败。写入前校验记录，分别验收替换前失败和替换后确认失败，未定期间保持关闭 |
| R7 | 重要 | 回退与用例缺少具体输入、顺序及结果归档。明确关闭新派发、关闭管理、回装相容制品及旧版本访问控制，记录未知格式原文件保全。各阶段由实施者留实际复跑证据，项目负责人裁决范围 |
| R8 | 轻微 | 命令以路径占位值直接赋给 `DSH_BIN`，说明真实入口、目标和制品参数 |
