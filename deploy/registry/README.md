# 企业私有 npm 与原生索引接入

状态：轻量模式评审稿；AIHUB 索引、企业接入与三目标安装仍待 G1/G2 核验。

[ADR-11/13](<../../docs/architecture/plugin-registry-source-decision.md>)确定企业私有 npm 为唯一插件制品源；AI 开发者平台（AIHUB）维护并托管 format-1 索引，DSH 原生「索引源」添加只读 URL，官方 `pluginManager` + pnpm 安装。首版索引只放自包含、Windows 10 amd64／统信 UOS 20 amd64／银河麒麟 aarch64 三目标通用的稳定版。

本仓库不自研 registry、不生成索引、不写前授权，也不把方案写成全通道白名单已验证。字段与验收见[索引契约](<../../docs/design/services/market-index.md>)、[轻量市场设计](<../../docs/design/plugins/forge-market.md>)与 [issue #12](https://github.com/hrygo/heluo-forge/issues/12)。

## 职责

| 对象 | 负责什么 | 不负责什么 |
|---|---|---|
| AIHUB | 插件预创建、Gitee 建仓、审查、npm 发布、维护并托管 format-1 索引、按时更新/撤回 | 终端安装、DSH 运行时 |
| 企业 npm 维护方 | 公网同步、内部制品、下载/发布权限、同版不可变、保留恢复与实际 ACL | 不把所有同步包自动当市场准入，不向终端开放公网备用源 |
| 管理员/平台组 | registry 与包名名单、DSH/终端发行矩阵、profile 基线、索引契约验收 | 不人工逐版录版本/摘要，不建审批数据库或索引生成器 |
| DSH 原生市场 | 读取索引、展示插件、调用官方 manager | 包体检查、企业审批、写前授权 |
| 用户 | 添加可信 AIHUB 索引 URL、选择精确版本 | 判断包是否合规 |

## 运行契约

1. **单 profile 单规范源。** 同一 profile 只绑定一个企业 npm 聚合入口，`fallbackRegistries: []`；后端多仓由既有私服聚合。入口只存本地配置并在打包时内置，不入 Git；允许内网 HTTP（已批准例外）。
2. **策展与自包含。** AIHUB 在发布前筛掉外部运行依赖、单平台、预发布与不兼容版本；peer 只能由已核验 DSH 基线满足，不自动补装。禁止终端触发的安装脚本、隐式 native 编译与外部 CDN。
3. **联网是企业内网。** registry、metadata/tarball、索引与展示资源只走获准内网；不关闭证书校验，不代理公网同名包；终端不直连公网。
4. **原生索引不是强授权。** 索引可读即可安装；没有 `installEnabled`、租约、写前复核或逐版本证据。删除索引只停止新的目录安装；角色与入口限制只能减少入口，不宣称 REQ-14/G2 全通道通过。
5. **版本不可变、更版非原子。** 同名同版本不可覆盖；更版按原生能力，没有通用 upgrade 时卸载后安装精确版本，不承诺自动回滚；撤回删索引并在私服阻断，已装代码独立处置。

## 待核验事实

| 接入事实 | 责任方 | 关闭要求 |
|---|---|---|
| 索引 URL 协议、匿名/网络准入、JSON 合法性 | AIHUB、IT | 三目标能添加并浏览；`validate-index.mjs` 通过 |
| `source.registry` 虚拟仓与终端 `.npmrc` 读权限 | 仓库维护方、IT | 三目标各安装同一精确版本成功 |
| 新版本 ≤10 分钟、撤回 ≤5 分钟 | AIHUB | 发布/删除演练与回执 |
| 同版不可变、隔离/撤回阻断、保留期 | 仓库维护方 | 覆盖发布演练、删除/隔离记录 |
| 目标 DSH/Node/pnpm/SDK 版本与三目标矩阵 | 平台发行方、IT | 冻结版本并完成实机安装 |

不在本仓库保存真实地址、token、证书私钥或生产配置；敏感参数经批准的受控渠道提供。方案发布不触发真实同步、安装、部署或 npm 发布。
