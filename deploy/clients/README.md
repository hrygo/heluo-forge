## 边界

- 不构建 Linux 桌面客户端；麒麟使用本机 Web，仅监听回环地址。
- 安装包与配置不得内置用户凭据或共享密钥。
- 签名、公证、MDM 与软件源由 IT 确认，仓库只保存可审查的构建与配置输入。
- 两端凭据与执行隔离须实机验证，配置文本不能证明隔离有效。
