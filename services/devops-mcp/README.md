# DevOps MCP 服务

状态：规划

当前不建设；本目录保留条件设计与职责入口，不是 DevOps CLI 接入的前置依赖。CLI 前提不成立只触发替代形态评审，不自动授权建设。

| 项 | 内容 |
|---|---|
| 形态 | 条件建设的独立 HTTP 服务（MCP，目标 `streamable-http`） |
| 职责 | 暴露只读查询工具面、校验令牌与受众、执行平台只读权限 |
| 不负责 | 不决定客户端策略，不保存用户长期凭据，不提供生产写操作，不替代 DevOps 平台本身 |
| 客户端 | [@heluo/forge-devops](../../packages/forge-devops/README.md) |
| 详细设计 | [DESIGN-011](../../docs/design/services/devops-mcp.md)（条件草案，已建立） |
| 实现状态 | 尚未建立服务清单、源码、测试或部署配置 |

## 边界

- 只读查询工具面，以用户故事/需求读取为主；具体清单由 DevOps 提供方澄清，不预设数量，不提供生产写操作。
- 若形态变更获准，按对应 MCP 规范暴露受保护资源元数据，校验令牌受众为本服务 canonical URI，并核定 REQ-12、WBS 与验收。
- 工具面或字段变更须与客户端约定通知与版本兼容方式。
- 超时或断流时按冻结规则处理，无法确认未执行时不接受传输层盲目重放。
- 当前 P1 以 CLI 只读闭环为准，不保留默认 `stdio` 验证或核心补丁工作项。
