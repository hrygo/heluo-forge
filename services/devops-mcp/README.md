# DevOps MCP 服务

状态：规划

| 项 | 内容 |
|---|---|
| 形态 | 独立 HTTP 服务（MCP，目标 `streamable-http`） |
| 职责 | 暴露只读查询工具面、校验令牌与受众、执行平台只读权限 |
| 不负责 | 不决定客户端策略，不保存用户长期凭据，不提供生产写操作，不替代 DevOps 平台本身 |
| 客户端 | [@heluo/forge-devops](../../packages/forge-devops/README.md) |
| 详细设计 | `docs/design/services/devops-mcp.md`（待编写，见[设计索引](../../docs/design/README.md)） |
| 实现状态 | 尚未建立服务清单、源码、测试或部署配置 |

## 边界

- 只读查询工具面，以用户故事/需求读取为主；具体清单由 DevOps 提供方澄清，不预设数量，不提供生产写操作。
- 按 MCP 规范暴露受保护资源元数据，校验令牌受众为本服务 canonical URI。
- 工具面或字段变更须与客户端约定通知与版本兼容方式。
- 超时或断流时按冻结规则处理，无法确认未执行时不接受传输层盲目重放。
- 本地 stdio 仅用于 P1 验证工具面，不作为生产形态。
