# 企业研发工具套件

面向研发工程师的协同工作台，集成 DevOps 变更、Gitee 代码托管与问题交付工作流，无需绑定企业账号即可独立使用。

## 主要功能

- **企业研发工具**（`设置 → 企业研发工具`）：统一查看 DevOps 与 Gitee 工具连接状态并管理参数。
- **DevOps 与 Gitee 协同**：支持变更查询、仓库与 Issue/PR 检索、评审辅助及受控提交。
- **问题交付 Skill**（`enterprise-issue-delivery`）：在对话中辅助完成单 Issue 核实与交付验证。

## 使用方式

1. 前往 **设置 → 企业研发工具** 查看工具就绪状态，默认自动复用本机已登录的 `dop` / `gh` 会话。
2. 如需单独指定 Token，可在对应工具面板底部填写，不会改动本机原有配置。
