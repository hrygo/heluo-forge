# 企业研发工具套件

面向企业研发工程师的一体化研发工作台套件，独立预装使用，不强制绑定企业账号底座，也不会改动默认个人账号、模型或本地凭据配置。

## 包含能力

- **企业研发工具工作台**（`设置 → 企业研发工具`）：集中收纳研发协同与代码托管工具面板，提供统一状态概览与环境详情折叠视图。
- **DevOps 研发协同（DOP）**：接入 `dop` CLI 工具面，支持在工作台查看工具就绪状态、配置环境参数与变更工作流检索。
- **Gitee 代码托管与交付工作流**：接入兼容 `gh` 的 Gitee CLI 工具面，支持仓库、Issue、Pull Request 查询、评审判断以及本地提交门禁校验。
- **企业问题交付规范 Skill**（`enterprise-issue-delivery`）：由用户在对话中显式触发，将单 Issue 核实、原生 Teamflow 执行协调与实际代码版本验证证据绑定在一起。
- **统一策略门禁**：预置与通用底座一致的策略动作目录，所有工具与命令执行前均经策略准入与审计记录。

## 凭据与使用方式

1. 安装后打开 **设置 → 企业研发工具** 查看 `DevOps (DOP)` 与 `Gitee` 的可执行文件定位及连接就绪情况。
2. **默认零配置复用**：各研发工具优先复用本机已完成登录的 `dop` / `gh` CLI 会话。
3. **按需指定独立 Token**：如需在当前工作区覆盖本机默认登录，可直接在对应工具面板底部的凭据区单独指定 Token（同时安装「企业账号与模型」时由宿主加密托管；仅安装本套件时提供明确提示，不修改个人 CLI 配置文件）。

## 注意事项

- 工具可见性不代表服务端权限放行，实际仓库、变更与评审权限仍由企业 DevOps 与 Gitee 服务端独立裁决。
- Gitee 如检测到本机存在明文持久化凭据文件，会在面板中给出安全提示；本套件不会自动修改或删除您原有的 CLI 配置文件。
