# Enterprise Engineering Suite

Standalone developer suite integrating DevOps changes, Gitee repositories, and issue delivery workflows without requiring an enterprise account.

## Features

- **Engineering Settings** (`Settings → Enterprise engineering`): View DevOps and Gitee connection status and configure options in one place.
- **DevOps & Gitee Collaboration**: Query changes, repositories, issues, and PRs, and assist with reviews and controlled commits.
- **Issue Delivery Skill** (`enterprise-issue-delivery`): Guide single-issue verification and delivery checks in chat.

## Usage

1. Open **Settings → Enterprise engineering** to check tool readiness; existing local `dop` / `gh` sessions are reused automatically.
2. Optionally set a workspace-specific token at the bottom of each panel without modifying your local CLI config.
