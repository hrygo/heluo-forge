# 企业账号用户指南

本指南说明开发骨架的账户界面，不是生产运行手册。返回[包入口](<../README.md>)；配置和验证限制见[开发者指南](<developer-guide.md>)。

默认组合使用 SQLite 值级加密存储，满足受信存储门禁时可执行登录、刷新和网关 Key 管理；存储不可用或门禁不满足时拒绝相关操作。真实目标平台、IAM 与网关尚无联调证据，本地模型执行门禁不代表真实企业授权或工具入口验收通过。

## 账户入口与状态

插件注册“设置 → 企业账号”账户页，并显示登录横幅。账户页展示主体、access 到期时间和网关凭据摘要，不显示已保存的令牌或 Key 原文。界面通常每 2 秒读取状态，账户页与横幅分别轮询，不保证同时更新；真实 DSH GUI 挂载与双端体验仍待验证。

| 界面状态 | 含义与处理 |
|---|---|
| IAM 未配置 | 配置不完整。把缺失项交给管理员处理，不通过重复登录修复。 |
| 未登录 | 本实例没有已采用的会话；配置与受信存储就绪后可发起登录。 |
| 等待浏览器登录 | Host 有登录中的状态；在浏览器完成，或使用页面的取消操作。 |
| 已登录 | 本实例采用了尚未过期的会话记录；不表示网关 Key 有效、企业调用已获授权或环境可以投产。 |
| 授权已过期 | access 已过期。普通可刷新会话可由轮询触发后台刷新；受信存储或其他依赖不可用时刷新被拒绝。 |
| IAM 暂不可达 | 查看具体错误及到期信息；不要把页面保留的旧状态当作服务端继续授权。 |
| 需要处理 | 根据错误提示处理配置、存储或失效会话；不是统一的密码错误。 |

只有与明确配置或本实例已验证的发行者上下文匹配的有效会话，才可恢复为“已登录”。恢复旧有效会话不主动访问 IAM；旧记录缺少可确认的发行者绑定时，不恢复身份、不返回令牌，也不删除记录。请联系管理员核对配置，或在具备受信存储的环境中主动重新登录。可读取的匹配旧公共会话仍可能被只读采用；新部署不会自动迁移旧凭据存储。机密 V2 记录不会被当前公共服务采用或作为旧公共记录删除；隔离测试组合已验证机密服务，但默认真实组合仍未接秘密来源，不能靠改配置切换或升级会话。

账户页仍由同源 HTTP 读取刷新状态；登录、显示与取消的操作方式保持不变。当前插件不自动切换默认模型。管理员设置观察目标后，Host 只读取模型提供方与当前选择，不更改模型、推理强度或其他设置，也不发起模型请求。这项内部观察不在账户页显示；账户显示“已登录”仍不代表默认模型已切换或企业模型调用已获授权。

## 登录不等于调用授权

“已登录”表示本地已采用IAM会话，“Key已配置”表示本地可以读取凭据；两者都不能代替当前人员对具体模型或工具用途的独立许可。隔离环境中的假执行验证不会开通企业调用能力，也不会更改默认模型。当前模型入口通过宿主 LLM 扩展门禁检查会话、凭证与目录；网关仍负责最终授权，工具及其他独立客户端不因此获得覆盖。

## 登录、继续登录与取消

在配置和受信存储就绪时，点击“登录企业账号”会请求 Host 创建或返回登录尝试，并打开浏览器授权页。密码在 IAM 页面输入，不在插件内输入。浏览器未打开时，使用页面给出的继续登录链接。

设置账户页显示本次登录链接时，可点击“复制登录链接”。它只复制本页已取得的链接，不补发登录，也不证明链接仍有效。链接含登录参数，只用于完成当前登录，不要粘贴到工单、聊天或日志。没有本页链接时，先使用“继续或重新登录”；横幅和引导仍提供打开链接入口，不提供这两个复制按钮。

如果账户页显示“等待浏览器登录”，但没有本页保存的链接，可以主动点击“继续或重新登录”：

- Host 可能返回当前共享登录尝试的链接，也可能根据当前状态新建尝试；这不是只恢复某个指定尝试的承诺。
- 同一账户页对正在发送的登录请求防重复。此规则不覆盖横幅、引导、其他标签或其他实例。
- 页面不自动取消、补发或重试登录。“取消登录”是显式请求；关闭浏览器标签页不等于 Host 已取消。
- 已发出的请求不能由页面撤回。较早的登录请求仍可能在退出后才到达 Host；旧响应虽不再覆盖账户页，Host 仍可能处于新的登录中状态。

首次处于未登录状态、且浏览器没有完成或跳过标记时，引导按“欢迎、登录、网关凭据、完成”四步显示。可以跳过引导或稍后配置 Key。完成屏和本地标记只记录引导进度及是否已配置 Key，不证明凭据有效或企业能力可用。

## 网关个人访问凭证

IAM 会话与网关个人访问凭证分开管理。Key 由 UAG 控制台提供；本插件不签发、不刷新、不探测。默认组合在受信联合存储就绪时支持保存与清除；存储不可用或联合门禁未满足时拒绝写入。恢复会话本身不保证 Key 写入条件已满足。

在受信联合存储就绪时，可在“设置 → 企业账号”粘贴 Key、填写设备标签后保存。保存还要求可取得 IAM 会话主体，且目标不是旧只读或不一致记录；同时填写网关地址时接受该网关提供的个人访问凭证；没有网关地址的旧 UAG 写入路径仍校验 `uag-` 加 32 位十六进制字符。建议到期日期只是提醒，不是服务端确认的有效期。

| 凭据状态 | 含义 |
|---|---|
| 未配置 | 本地未解析到已保存的值。 |
| 已配置 | 本地值及元数据可读取；不证明 Key 可用、未吊销或真实归属正确。 |
| 属于其他账号，请核对记录 | 录入人与当前账户主体不同；不证明 Key 的服务端所有者，也不表示现有记录可以直接覆盖。 |
| 记录不一致，已保留 | 值或元数据缺失、损坏或不一致。页面不自动删除、迁移或修复；先由维护者核对，不以反复录入覆盖。 |
| 状态未知 | 页面尚未取得可信结果；刷新核实，不按“未配置”处置。 |

换账号、启动恢复、取消登录及普通退出保留 Key。旧格式和不一致记录保持只读，不自动补齐字段或认领归属；即使测试环境具备联合存储，也不能用保存或清除把它们隐式迁移。当前没有自动修复入口，请维护者核对，不手工删除凭据文件。

对可变更的新格式，清除只逻辑移除本地值并保留防迟到写入的标记，不吊销 UAG 服务端 Key，也不退出 IAM，更不证明物理擦除。保存会重读当前存储的会话主体；排队期间的本地退出、卸载或凭据提供方变化会拒绝尚未提交的操作。提交或回执异常时仍可能已生效：先刷新核实，不自动重试，不依据按钮或异常推断“已删”或“完全未动”。

本地凭据使用值级加密 SQLite 与独立文件 keyring；文件权限不等于系统钥匙串保护，目标机的账户隔离和权限仍待验证。不要把 Key、令牌、授权 URL 或回调 URL 粘贴到工单、聊天或日志。

## 退出的结果与边界

点击“退出”后，账户页立即隐藏旧账户视图和旧登录链接，等待 Host 返回；它不采用退出前或退出过程中的迟到轮询结果。隐藏旧视图只是页面行为，不证明持久会话或服务端授权已经清除。

| 结果 | 页面可能显示 | 如何理解 |
|---|---|---|
| 本地清理完成，访问令牌已撤销 | 已退出：访问令牌已撤销；刷新令牌无法撤销，将在服务端自然过期。 | 访问令牌实时失效，不牵连同会话的其他应用；刷新令牌在服务端保留到自然过期，不能据此宣称该授权及派生授权已全部终结。 |
| 撤销被拒绝、失败或结果未知 | 无法清除本设备的登录信息，请联系管理员。 | 已写入的退出 pending 状态会保留，不报告本地清理完成，也不自动重发撤销请求。旧令牌不再由本服务或 CLI 返回，但可能仍在服务端有效。 |
| 未配置撤销端点 | 未登录 | 只做本地清理，未向服务端撤销访问令牌；“未登录”不等于服务端已退出。 |
| 本地凭据清理失败 | “无法清除本设备的登录信息”或“退出结果未确认，Host 不可达；请刷新核实” | 不宣称退出成功。未获信任的存储上不修改持久会话、不发送撤销请求；重启仍可能恢复旧会话。 |

逻辑清理不等于物理删除。即使访问令牌撤销返回成功，也不能据此证明刷新令牌、刷新后代或其他设备授权都已失效。普通退出保留网关 Key；可选的浏览器 RP 登出也不能替代当前设备授权的完整撤销证据。

结果未知时先刷新核实，并将非敏感错误码交给管理员。不要通过删除凭据文件、清空记录或反复重放操作来猜测恢复结果。

## 复制脱敏诊断

账户页可点击“复制脱敏诊断”，读取中或无法取得状态时也可复制未知状态的本页快照。诊断只含状态、已知错误码等最小信息，不含主体、到期时间、服务器地址、凭据、设备标签或输入草稿。它不代表 Host 的实时状态，也不证明服务端授权正常。

复制不会额外请求 Host，不自动发送、下载或读取已有剪贴板。浏览器拒绝权限或不提供剪贴板 API 时，页面显示未确认提示并保留原内容，不自动重试。可先核对页面错误码，再决定是否重新点击；不要把登录链接当作脱敏诊断发送。

成功提示只表示浏览器确认了本次剪贴板写入。退出、取消或新登录后，旧复制结果不再更新页面；已发送给浏览器的写入无法撤回，也不会擅自清空你的剪贴板。

## 常见错误与保留内容

- `IAM_ATOMIC_STORE_UNVERIFIED`：存储原子性没有受信确认。门禁未满足时拒绝登录或刷新；联系维护者，不尝试以配置开关绕过。
- `IAM_GATEWAY_ATOMIC_UNVERIFIED`：Key 与元数据的联合写入未获受信确认；门禁未满足时保存和清除不可用，不能用单记录存储配置绕过。
- `IAM_GATEWAY_LEGACY_READ_ONLY`：旧格式或不一致记录只读保留，没有自动迁移或修复入口。
- `IAM_GATEWAY_CHANGED`：快照或提交前本地检查已变化，本次未确认成功；先刷新核对，不自动重放。
- `IAM_GATEWAY_WRITE_UNKNOWN`：提交结果无法确认，可能已生效；不补偿清理，也不直接重试。
- `IAM_GRANT_CONTEXT_MISMATCH`：会话发行者无法确认，或与当前发行者、应用、用途不匹配。旧记录保留，请管理员核对正式配置；不要从旧记录复制字段来绕过检查。
- 凭据存储不可用、损坏或清理失败：保留错误提示，联系管理员核查；不要上传凭据库文件。
- 页面会话不可用：刷新页面核实宿主连接。回调无效或登录尝试过期：按界面提示主动重新登录，不复用旧回调链接。
- `IAM_REAUTH_REQUIRED`：刷新结果不能安全采用，当前请求不返回旧令牌；需要重新登录，登录仍受存储和身份门禁约束。
- 无法读取状态或 Host 不可达：显示的是未知结果，不表示“已退出”或“没有 Key”。

普通禁用、卸载或重载插件会停止它的运行时资源，但保留持久 IAM 会话和网关 Key，不执行远端撤销；再次启用后可能恢复会话。显式退出也不删除工作区、会话文件或个人数据。已有旧凭据引用不在启动时自动删除，保留它们不代表已阻止其他组件消费。

生产能力、存储安全及服务端授权的限制见[开发者指南：限制与生产门禁](<developer-guide.md#限制与生产门禁>)。


## 网关地址、个人访问凭证与模型列表

在具备受信存储的环境登录后，打开“设置 → 企业账号”，填写网关地址和对应的个人访问凭证，点击保存。地址中的路径按填写内容使用，不自动补齐 `/v1`；网关要求 `/v1` 时须填写该路径。支持 HTTP 和 HTTPS，但 HTTP 不提供传输加密或端点身份认证，个人 Key 和业务内容可能被窃取或篡改。地址不得包含用户名、密码、查询参数或片段。

Key 保存后不再显示。修改地址时须重新填写对应的 Key；输入中的修改会显示“有未保存的更改”，只有保存成功才会替换原配置。应用用保存的 Key 请求所填地址下的 `/models`，并在企业账号页显示模型列表；可点击“刷新模型列表”重新获取。目录成功返回不代表每个模型调用均已获网关授权。

模型要"启用后"才能用。列表来自所配置的网关目录，但你不会一次性看到全部可用：模型右侧标着"已启用"的才会出现在对话的模型选择里。首次同步时系统会自动启用列表中的第一个模型（标"默认可用"，默认 `200K` 上下文窗口、`64K` 最大输出），所以不配置也能直接对话；对于其他未启用的模型，你可以直接点击模型行右侧的“一键启用”（或工具栏的“全部默认启用”），无需展开配置即可采用默认参数一步启用并立即生效。也可展开“精细配置”后点“启用模型”再点“保存模型配置”。全部停用后再保存是允许的，此时对话里没有可选模型。

模型列表中的每个模型都可以单独微调：显示名称、上下文窗口（默认 `200K`，支持一键点击 `64K`、`128K`、`200K`、`256K`、`1M` 预设或自定义输入）、最大输出 Token（默认 `64K`，支持 `8K`～`128K` 快捷预设）、是否允许粘贴图片、推理强度档位与上下界区间（开放 `Off`、`Low`、`Medium`、`High`、`XHigh`、`Max` 六档，支持固定单档或自由设定推理强度下界与上界，如 `Low ~ XHigh`，当所选下界高于上界时自动对齐）。这些设置只影响本机这次使用的模型参数，不写企业侧配置，也不改动网关返回的目录。"恢复默认参数"或"默认参数启用"只清掉你改过的值，模型仍是启用状态；要让它从对话里消失请点"停用模型"。存在未保存的微调修改时，底部会提示“待保存模型配置变更”并支持一键“放弃修改”。选择与参数保存在本机宿主侧（按企业账号区分），**会跨重启保留**；换设备不会同步，同一设备以最近一次保存的为准。若保存时提示"已在本机生效但未能写入持久存储"，说明这次写入没落盘，重启后需要重新保存。

关闭设置，在对话窗口选择模型并发送消息。应用不会替你覆盖已有默认模型。退出或登录过期后，模型列表清空，新请求要求重新登录；历史对话仍保留。重新登录后会重新获取列表。网关拒绝 Key 与登录失效分别提示；无法连接、权限不足或列表格式错误按页面提示处理，不反复重发请求。
