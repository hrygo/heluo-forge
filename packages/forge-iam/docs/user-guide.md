# 企业账号用户指南

本指南说明开发骨架的账户界面，不是生产运行手册。返回[包入口](<../README.md>)；配置和验证限制见[开发者指南](<developer-guide.md>)。

**当前默认组合不能发起新登录、刷新，也不能保存或清除网关 Key。** 这是凭据存储安全能力尚未获得验证的限制，不是输入密码或反复点击能够解决的问题。真实 IAM 与网关尚无联调证据，企业模型和工具的实际执行门禁也未接通。

## 账户入口与状态

插件注册“设置 → 企业账号”账户页，并显示登录横幅。账户页展示主体、access 到期时间和网关凭据摘要，不显示已保存的令牌或 Key 原文。界面通常每 2 秒读取状态，账户页与横幅分别轮询，不保证同时更新；真实 DSH GUI 挂载与双端体验仍待验证。

| 界面状态 | 含义与处理 |
|---|---|
| IAM 未配置 | 配置不完整。把缺失项交给管理员处理，不通过重复登录修复。 |
| 未登录 | 本实例没有已采用的会话。默认组合仍会拒绝新登录。 |
| 等待浏览器登录 | Host 有登录中的状态；在浏览器完成，或使用页面的取消操作。 |
| 已登录 | 本实例采用了尚未过期的会话记录；不表示网关 Key 有效、企业调用已获授权或环境可以投产。 |
| 授权已过期 | access 已过期。普通可刷新会话可由轮询触发后台刷新，但默认组合阻断刷新。 |
| IAM 暂不可达 | 查看具体错误及到期信息；不要把页面保留的旧状态当作服务端继续授权。 |
| 需要处理 | 根据错误提示处理配置、存储或失效会话；不是统一的密码错误。 |

只有与明确配置或本实例已验证的发行者上下文匹配的有效会话，才可恢复为“已登录”。恢复旧有效会话不主动访问 IAM；旧记录缺少可确认的发行者绑定时，不恢复身份、不返回令牌，也不删除记录。请联系管理员核对配置，或在具备受信存储的环境中主动重新登录。匹配的旧公共会话仍可能在未经验证的存储上被只读采用，默认登录门禁不等于停用所有旧会话。机密 V2 记录不会被当前公共服务采用或作为旧公共记录删除；隔离测试组合已验证机密服务，但默认真实组合仍未接秘密来源，不能靠改配置切换或升级会话。

账户页仍由同源 HTTP 读取刷新状态；登录、显示与取消的操作方式保持不变。当前插件不自动切换默认模型。管理员设置观察目标后，Host 只读取模型提供方与当前选择，不更改模型、推理强度或其他设置，也不发起模型请求。这项内部观察不在账户页显示；账户显示“已登录”仍不代表默认模型已切换或企业模型调用已获授权。

## 登录不等于调用授权

“已登录”表示本地已采用IAM会话，“Key已配置”表示本地可以读取凭据；两者都不能代替当前人员对具体模型或工具用途的独立许可。隔离环境中的假执行验证不会开通企业调用能力，也不会更改默认模型。当前验证不覆盖真实模型或工具的执行入口，不能据此判断这些入口已受本插件保护。

## 登录、继续登录与取消

在具备受信测试存储的隔离环境中，点击“登录企业账号”会请求 Host 创建或返回登录尝试，并打开浏览器授权页。密码在 IAM 页面输入，不在插件内输入。浏览器未打开时，使用页面给出的继续登录链接。

设置账户页显示本次登录链接时，可点击“复制登录链接”。它只复制本页已取得的链接，不补发登录，也不证明链接仍有效。链接含登录参数，只用于完成当前登录，不要粘贴到工单、聊天或日志。没有本页链接时，先使用“继续或重新登录”；横幅和引导仍提供打开链接入口，不提供这两个复制按钮。

如果账户页显示“等待浏览器登录”，但没有本页保存的链接，可以主动点击“继续或重新登录”：

- Host 可能返回当前共享登录尝试的链接，也可能根据当前状态新建尝试；这不是只恢复某个指定尝试的承诺。
- 同一账户页对正在发送的登录请求防重复。此规则不覆盖横幅、引导、其他标签或其他实例。
- 页面不自动取消、补发或重试登录。“取消登录”是显式请求；关闭浏览器标签页不等于 Host 已取消。
- 已发出的请求不能由页面撤回。较早的登录请求仍可能在退出后才到达 Host；旧响应虽不再覆盖账户页，Host 仍可能处于新的登录中状态。

首次处于未登录状态、且浏览器没有完成或跳过标记时，引导按“欢迎、登录、网关凭据、完成”四步显示。可以跳过引导或稍后配置 Key。完成屏和本地标记只记录引导进度及是否已配置 Key，不证明凭据有效或企业能力可用。

## 网关个人 Key

IAM 会话与网关个人 Key 分开管理。Key 由 UAG 控制台提供；本插件不签发、不刷新、不探测。当前默认组合只读取既有凭据摘要，保存和清除均因联合存储能力未核验而被拒绝；即使已恢复旧 IAM 会话，也不因此取得 Key 写入能力。按钮仍可显示，点击不能解除 Host 门禁。

仅在具备独立受信联合存储的隔离测试环境中，可在“设置 → 企业账号”粘贴 Key、填写设备标签后保存。保存还要求可取得 IAM 会话主体，且目标不是旧只读或不一致记录；格式为 `uag-` 加 32 位十六进制字符。建议到期日期只是提醒，不是服务端确认的有效期。

| 凭据状态 | 含义 |
|---|---|
| 未配置 | 本地未解析到已保存的值。 |
| 已配置 | 本地值及元数据可读取；不证明 Key 可用、未吊销或真实归属正确。 |
| 属于其他账号，请核对记录 | 录入人与当前账户主体不同；不证明 Key 的服务端所有者，也不表示现有记录可以直接覆盖。 |
| 记录不一致，已保留 | 值或元数据缺失、损坏或不一致。页面不自动删除、迁移或修复；先由维护者核对，不以反复录入覆盖。 |
| 状态未知 | 页面尚未取得可信结果；刷新核实，不按“未配置”处置。 |

换账号、启动恢复、取消登录及普通退出保留 Key。旧格式和不一致记录保持只读，不自动补齐字段或认领归属；即使测试环境具备联合存储，也不能用保存或清除把它们隐式迁移。当前没有自动修复入口，请维护者核对，不手工删除凭据文件。

对可变更的新格式，清除只逻辑移除本地值并保留防迟到写入的标记，不吊销 UAG 服务端 Key，也不退出 IAM，更不证明物理擦除。保存会重读当前存储的会话主体；排队期间的本地退出、卸载或凭据提供方变化会拒绝尚未提交的操作。提交或回执异常时仍可能已生效：先刷新核实，不自动重试，不依据按钮或异常推断“已删”或“完全未动”。

非 keychain 来源可能显示“未受系统钥匙串保护”。0600 文件权限不等于系统钥匙串保护，不是生产替代方案。不要把 Key、令牌、授权 URL 或回调 URL 粘贴到工单、聊天或日志。

## 退出的三类结果

点击“退出”后，账户页立即隐藏旧账户视图和旧登录链接，等待 Host 返回；它不采用退出前或退出过程中的迟到轮询结果。隐藏旧视图只是页面行为，不证明持久会话或服务端授权已经清除。

| 结果 | 页面可能显示 | 如何理解 |
|---|---|---|
| 本地逻辑清理得到确认 | 未登录 | 在受信存储上，会话记录被逻辑清除或确认不存在。远端撤销可能成功响应，也可能未配置而跳过；未登录不证明整个授权及刷新后代已经撤销。 |
| 本地逻辑清理完成，撤销请求失败 | 本地已退出，但服务端撤销未确认 | 本实例退出不因远端失败回滚；服务端授权状态仍需核实，不宣称 Key 或浏览器 SSO 已退出。 |
| 清理或请求结果未知 | 本地凭据清理失败，或“退出结果未确认，Host 不可达；请刷新核实” | 不宣称退出成功。默认不受信存储上不修改持久会话、不发送撤销请求；重启仍可能恢复旧会话。网络失败也不能推出 Host 未执行操作。 |

逻辑清理不等于物理删除。即使撤销端点返回成功，也不能据此证明所有 access token、刷新后代或其他设备授权都已失效。普通退出保留网关 Key；可选的浏览器 RP 登出也不能替代当前设备授权的完整撤销证据。

结果未知时先刷新核实，并将非敏感错误码交给管理员。不要通过删除凭据文件、清空记录或反复重放操作来猜测恢复结果。

## 复制脱敏诊断

账户页可点击“复制脱敏诊断”，读取中或无法取得状态时也可复制未知状态的本页快照。诊断只含状态、已知错误码等最小信息，不含主体、到期时间、服务器地址、凭据、设备标签或输入草稿。它不代表 Host 的实时状态，也不证明服务端授权正常。

复制不会额外请求 Host，不自动发送、下载或读取已有剪贴板。浏览器拒绝权限或不提供剪贴板 API 时，页面显示未确认提示并保留原内容，不自动重试。可先核对页面错误码，再决定是否重新点击；不要把登录链接当作脱敏诊断发送。

成功提示只表示浏览器确认了本次剪贴板写入。退出、取消或新登录后，旧复制结果不再更新页面；已发送给浏览器的写入无法撤回，也不会擅自清空你的剪贴板。

## 常见错误与保留内容

- `IAM_ATOMIC_STORE_UNVERIFIED`：存储原子性没有受信确认。默认组合会拒绝登录或刷新；联系维护者，不尝试以配置开关绕过。
- `IAM_GATEWAY_ATOMIC_UNVERIFIED`：Key 与元数据的联合写入未获受信确认；默认保存和清除均不可用，不能用单记录存储配置绕过。
- `IAM_GATEWAY_LEGACY_READ_ONLY`：旧格式或不一致记录只读保留，没有自动迁移或修复入口。
- `IAM_GATEWAY_CHANGED`：快照或提交前本地检查已变化，本次未确认成功；先刷新核对，不自动重放。
- `IAM_GATEWAY_WRITE_UNKNOWN`：提交结果无法确认，可能已生效；不补偿清理，也不直接重试。
- `IAM_GRANT_CONTEXT_MISMATCH`：会话发行者无法确认，或与当前发行者、应用、用途不匹配。旧记录保留，请管理员核对正式配置；不要从旧记录复制字段来绕过检查。
- 凭据存储不可用、损坏或清理失败：保留错误提示，联系管理员核查；不要上传凭据库文件。
- 页面会话不可用：刷新页面核实宿主连接。回调无效或登录尝试过期：按界面提示主动重新登录，不复用旧回调链接。
- `IAM_REAUTH_REQUIRED`：刷新结果不能安全采用，当前请求不返回旧令牌；需要重新登录。默认组合本身仍有登录门禁。
- 无法读取状态或 Host 不可达：显示的是未知结果，不表示“已退出”或“没有 Key”。

普通禁用、卸载或重载插件会停止它的运行时资源，但保留持久 IAM 会话和网关 Key，不执行远端撤销；再次启用后可能恢复会话。显式退出也不删除工作区、会话文件或个人数据。已有旧凭据引用不在启动时自动删除，保留它们不代表已阻止其他组件消费。

生产能力、存储安全及服务端授权的限制见[开发者指南：限制与生产门禁](<developer-guide.md#限制与生产门禁>)。
