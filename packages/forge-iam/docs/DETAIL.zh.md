# 企业账号与模型认证

面向企业成员的通用身份与模型接入插件，负责企业账号登录、AI 服务个人密钥管理与企业模型目录启用。

## 主要功能

- **企业账号登录**（`设置 → 企业账号`）：基于标准 OIDC 授权码与 PKCE 完成企业统一身份认证，支持令牌自动刷新、会话状态诊断与安全退出。
- **AI 服务密钥管理**（`设置 → 企业账号`）：录入、更换或清除个人企业 AI 网关密钥（支持多端同步或本地加密存储），不与公网个人密钥混用。
- **企业模型配置**（`设置 → 企业模型`）：拉取并展示企业 AI 网关支持的模型目录，支持一键按默认参数启用模型、手动补充自定义模型 ID，以及调节上下文窗口、最大输出和深度推理等级上下限。

## 使用说明

1. 安装后前往 **设置 → 企业账号** 完成企业身份登录，并在 AI 服务区配置网关密钥。
2. 切换到 **设置 → 企业模型**，点击 **一键启用**（或顶部 **全部默认启用**）激活所需模型；如有未列入目录的模型，可点击 **手动添加** 单独登记。
3. 启用完成后即可在对话界面直接选择已启用的企业模型。

## 安全与边界

- 所有企业身份会话与网关个人密钥由安全凭据服务加密托管，退出账号后自动停止分发模型凭据。
- 本插件仅面向企业统一认证与企业模型管理，不包含特定业务域功能。
- 企业身份提供商、AI 网关与加密存储的实际连通表现以管理员环境部署为准。
