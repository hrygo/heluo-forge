# 企业账号与模型

面向全体企业成员的通用企业底座，统一管理企业身份登录、企业 AI 网关接入、企业模型目录与加密凭据存储，不含其他业务域扩展。

## 包含能力

- **企业账号登录**（`设置 → 企业账号`）：支持企业统一身份认证、网关地址与个人密钥录入，以及会话过期刷新与安全退出。
- **企业模型管理**（`设置 → 企业模型`）：支持同步企业 AI 网关模型目录、一键按默认参数启用模型、手动补充企业网关内的定制模型，并按需展开上下文上限、输出长度与推理级别精细配置。
- **加密凭据托管**：停用原生明文凭据文件提供方，改由 SQLite 值级加密与本地钥匙串托管认证密钥。
- **企业门禁策略底座**：预置通用策略服务与独占防旁路检测，停用公网个人账号、官方 API Key 直连与自由添加第三方模型入口。

## 快速上手

1. 安装后打开 **设置 → 企业账号**，完成企业统一身份登录。
2. 在 AI 服务区域填写或核对企业 AI 网关地址与个人密钥，确认网关连通就绪。
3. 切换到 **设置 → 企业模型**，在同步的模型目录中点击 **一键启用**，或按需添加定制模型与调整参数，随后即可在对话窗口选择已启用模型。

## 注意事项

- 本底座停用个人公网 DeepSeek 账号、开放网关配置与明文凭据保存；卸载或停用本包后，原生默认条目将按配置层规则恢复。
- 默认策略配置使用本地内存审计占位，实际企业环境中的长期合规审计、真实 IAM 端点与 OS 凭据集成以管理员部署为准。
- 本包专注企业统一身份认证、AI 网关接入与企业模型目录管理，不包含其他业务域扩展；如需额外业务套件，可在插件市场按需安装对应功能包。
