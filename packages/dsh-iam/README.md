# @corp/dsh-iam

状态：规划

| 项 | 内容 |
|---|---|
| 形态 | Host 插件 + Client 插件 |
| 职责 | 授权流程、令牌 broker、按资源取用与刷新、账户状态 UI |
| 不负责 | 不自建账号库，不签发企业令牌，不代理模型内容，不决定服务端最终权限 |
| 衔接点 | `credentials`、`authorization`、`webServer`、`llm` |
| 详细设计 | `docs/design/plugins/dsh-iam.md`（待编写，见[设计索引](../../docs/design/README.md)） |
| 实现状态 | 尚未建立 `package.json`、源码与测试 |

## 边界

- 原生客户端采用系统浏览器与授权码 + PKCE，回调限定 loopback；不在应用内收集企业密码。
- 按目标资源取得令牌，缓存键包含资源与 scope；切换身份清理旧缓存。
- 刷新凭据只发往 IAM，不交给网关、模型、工具或账户界面。
- 本地会话可先于企业授权存在；企业资源调用需要有效授权，两者不混为一谈。
- 接口以 IAM 回函与联调为准，未核验前不把字段或端点写成既定事实。
