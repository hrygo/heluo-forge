# @heluo/forge-sdd

状态：规划

| 项 | 内容 |
|---|---|
| 形态 | 最小企业指引 + 必要 CLI/CI 校验，优先复用 |
| 职责 | 规范驱动开发的产物契约、freeze 与指纹、归档与 PR 描述 |
| 不负责 | 不接管对话流程，不替代代码评审，不自行执行路径门禁 |
| 衔接点 | `skill-filesystem`；路径规则由 [@heluo/forge-policy](../forge-policy/README.md) 执行 |
| 详细设计 | [详细设计](../../docs/design/plugins/forge-sdd.md)（草案，已建立；状态见[设计索引](../../docs/design/README.md)） |
| 实现状态 | 尚未建立 `package.json`、源码与测试 |

## 边界

- 只守三条不变量：规范与代码不漂移、一次交付原子、变更可追溯。
- 阶段写入元数据，不用阶段编号驱动对话顺序。
- 路径规则集中在策略插件，不在本包维护另一套钩子。
- 按需复用可验证的 CLI/CI，不固定新工具数量，不引入第二套流程引擎。
