# @heluo/forge-brand

状态：可用（开发骨架）。品牌令牌校验、回退语义与随包资产的字节一致性具有本地测试；宿主品牌/主题面的实际消费与双端渲染覆盖待真实宿主联调（设计 §12 未决项），本地测试不代表生产就绪。

| 项 | 内容 |
|---|---|
| 形态 | 配置 bundle（无 client 面） |
| 职责 | 产品名、Logo、主色、默认主题、页脚与支持链接六字段的品牌令牌：校验、归一与安全回退 |
| 身份默认 | 产品名「河洛 Forge 企业版」、主色 `#2563eb`（双底 ≥3:1）、主题 `system`、页脚「企业内部使用」、Logo 为河洛苍螭彩色图文组合 |
| 挂载 | `apply(ctx, config)` 校验归一后经 `ctx.provide('forge-brand')` 暴露令牌与 Logo 字节；缺宿主接缝降级为记录 `HOST_SEAM_UNAVAILABLE`，不失败装载 |
| 随包资产 | `icon.svg` 与 `assets/wordmark-color.svg` 与品牌源文件逐字节一致并经品牌 manifest SHA-256 交叉校验（package-shape 测试） |
| 不负责 | 不隐含白标客户端发行授权，不修改核心界面结构，不隐藏安全提示、审批与审计入口 |
| 衔接点 | `forge-brand` 服务、宿主品牌/主题面（待实测） |
| 详细设计 | [详细设计](../../docs/design/plugins/forge-brand.md)（状态见[设计索引](../../docs/design/README.md)） |

## 边界

- 只覆盖受支持的品牌与主题 token，不注入脚本或远程资源；Logo 引用只接受包内相对路径，外链与越界路径一律拒绝并回退上游默认。
- 品牌配置不等于可对外发行独立客户端；白标需范围变更并单独立项。
- 图标与字体须有可用授权，仓库内不放入来源不明的素材。
- 任一字段异常都回退品牌默认并记录回执，不出现空产品名或空 Logo；产品名超 32 字符截断加省略号。
