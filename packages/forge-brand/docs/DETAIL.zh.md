# 河洛品牌外观

提供「河洛 Forge 企业版」的品牌外观令牌：产品名称、应用内 Logo、主色、默认主题、页脚文案与支持链接。

## 主要能力

- **品牌令牌**：包内默认值即「河洛 Forge 企业版」身份（产品名「河洛 Forge 企业版」、主色 `#2563EB`、默认主题 `system`、页脚「企业内部使用」、Logo 为河洛苍螭彩色图文组合），经 `ctx.provide('forge-brand')` 对宿主可用。
- **安全回退**：任一字段异常都回退上游兼容默认值并记录回执，不会出现空产品名或空 Logo；主色需在品牌浅底 `#FFFFFF` 与深底 `#070C16` 上同时保持不低于 3:1 的非文本对比度，不足即回退默认主色。
- **外链拒绝**：Logo 与支持链接只接受包内相对路径 / 合法 URL；带协议、协议相对 `//` 或越界 `..` 的 Logo 引用一律拒绝加载，回退上游默认。
- **超长截断**：产品名超过 32 字符按字符截断加省略号。

## 边界

- 品牌化不隐藏、不弱化安全提示、审批与审计入口；不做白标与多租户外观。
- 宿主品牌/主题面的实际消费与双端渲染覆盖待真实宿主联调（设计 §12 未决项）；缺少宿主接缝时本包降级为仅提供令牌，不影响装载。
