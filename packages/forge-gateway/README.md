| 职责 | 企业模型接入配置：端点、模型白名单、错误与重试策略 |

## 边界

- 401 只表示令牌未被接受；403 表示权限或模型未授权；429 表示额度耗尽，客户端不自动重试。
- 刷新后重试仅在能证明请求未执行且未开始输出时允许，且至多一次。
- 额度与计量以网关为准，客户端不建第二套账。
- 契约字段以 [AI 网关契约](../../docs/contracts/gateway-contract.md) 为唯一真源。
