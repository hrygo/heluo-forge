## 边界

- 401 区分长效凭据无效、IAM 令牌失效与凭据吊销；403 表示权限、模型或身份归属不符；429 区分预算耗尽（展示 `reset_at`，不重试）与速率超限（按 `Retry-After` 退避，上限 3 次）。
- 令牌在发送前按本地有效期刷新，刷新后发出的是新请求；网关返回 401/403 后不重放已发送请求。
- 额度与计量以网关为准，客户端不建第二套账。
- 契约字段以 [AI 网关契约](../../docs/contracts/gateway-contract.md) 为唯一真源。
