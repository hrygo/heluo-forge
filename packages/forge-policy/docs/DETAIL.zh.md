# 企业门禁策略引擎

企业扩展套件的统一策略核心，在宿主工具管线与命令执行前对动作目录、目标边界、敏感路径与数据外发进行一致性准入校验与审计记录。

## 核心能力

- **受控动作目录与统一门禁**：仅对策略目录中已登记并放行的动作放行执行；未登记、未启用、缺少目标或审计不可用时默认拒绝（fail closed）。
- **受保护路径防护**：基于平台路径规范化与软链解析，对 `$DSH_HOME/**` 等核心运行时目录实施不可覆盖的写前拒绝。
- **敏感外发确认（C3）**：为绑定 `(action, target, contentDigest)` 的数据外发行为提供确认拦截，取消或超时即阻断下游执行。
- **前后置决策审计**：调用前登记执行凭据，执行完成后核销结清，异常中断不伪造完成状态。

## 边界说明

- 本插件仅面向在目录中显式登记的工具及声明类别；未纳入登记范围的工具不声称策略覆盖。
- 不提供 `fail-open` 绕过模式或基于自由正则黑名单的安全承诺；真实服务端权限仍由企业上游独立控制。
