# @heluo/forge-policy

状态：可用（动作分类与内置词表、统一门禁、内容与流程规则、组织策略信封验签、范围票据、受保护路径、C3 外发确认、必要审计前置；未接企业环境，未做双端实机）

一句话：按类别给出默认决策（只读放行、研发写放行并叠加内容与流程规则、推送逐次确认、人工留痕恒拒），登记只用来声明"这个动作在本装配里存在"；未登记、未开放、目标缺失、身份缺失或确认通道不可用一律拒绝，组织信封只能收紧。

| 项 | 内容 |
|---|---|
| 形态 | Host 插件（提供 `policy` 服务） |
| 职责 | 工具门禁、路径规则、`$DSH_HOME` 硬拒绝、客户数据外发确认、决策审计 |
| 不负责 | 不替代服务端鉴权，不维护独立 hook 引擎 |
| 衔接点 | `tools.guard`（单调硬拒绝）、`tools/pre-execute`（需确认动作）、`ctx.commands`（命令面）、`otel` |
| 详细设计依据 | CORP-DSH-DESIGN-003（草案，整仓评审材料不随包分发）；本页说明现行代码与边界 |
| 实现状态 | 动作词表与判定、内容与流程规则、组织信封验签与上限合成、范围票据、guard 与确认阶段、命令包装、受保护路径、C3 外发、决策审计与卸载清理已实现，并有离线用例与宿主探针覆盖；宿主确认通道超时、企业环境与双端实机未验 |

## 当前实现

| 项 | 状态 |
|---|---|
| 目录 | `compileCatalog`：只接受 `action`/`target`/`revision`/`enabled`，未知字段与未知动作一律拒绝；`target` 必须与类别一致、`enabled` 必须是显式布尔；类别与默认决策由内置词表给出，运行期不读工具自报属性 |
| 判定 | `decideAction` + `composeDecision`：未登记 / 未开放 / 目标缺失 / 人工留痕 / 需确认分别给出规则名；**自报 `readOnly` 等声明不参与任何规则**；写动作另叠内容规则（HARD 拒绝、SOFT 转确认）、流程规则（事实源不可用记 `unevaluated` 而非拒绝）与组织信封上限，三态取最严，`prepare` 绑定、`guard` 重验 |
| 工具面 | `ctx.tools.guard` 单调拒绝；必须持有同一执行对象的未消费审计收据，调用身份或参数变化即拒绝；`confirm` 动作还须经过确认阶段 |
| 命令面 | `policy.registerCommand`：未登记动作拒绝注册；判定、路径、确认、前置审计与结清复用工具屏障；简单命令须有明确目标，结构化命令提供 `resolveArguments(invocation)`，处理函数第二参数为规范化参数；命令名不能冒充目标 |
| 覆盖范围 | 只处理被显式登记为业务动作的工具，以及显式声明的类别（如 `bash → shell.exec`）；未登记的工具不属于本门禁作用域，不声称覆盖 |
| 受保护路径 | 根按 `$DSH_HOME/**` 模板解析（缺席回落 `~/.dsh`）；绝对化 + 词法折叠 + `realpath` + 平台大小写归一后判断包含；直接、穿越、symlink 别名一律拒绝，且**已获确认也不可翻转** |
| C3 外发确认 | 确认绑定 `(action, target, contentDigest)`；取消/过期/超时/不可用一律拒绝；渲染只出字段名与摘要前缀，并提供金丝雀检查 |
| 范围票据 | `createScopeLedger`：绑定身份、变更号、仓库、动作与已读版本，进程内保存、不落盘、不因使用而消费；同一任务内的重复写复用同一票据，撤销/越界/身份变化即拒；无 IAM 身份或变更号不签发票据 |
| 组织信封 | `verifyEnvelope`：`heluo.policy.org.v1`、Ed25519、`issued_by`/`issued_at` 被签名覆盖，`caps` 只能收紧，验签失败时写动作全拒、读不受影响；信封缺失即个人模式 |
| 确认生命周期 | 逐次确认（`confirmations`）校验 `(action, target, contentDigest)` 与绑定版本并一次性消费；范围票据按任务范围复用；显式 key 只是定位提示，不替代当前 scope；真实宿主确认通道接线需另验 |
| 必要审计 | 前置记录绑定同一执行对象及参数摘要；`tools/post-execute` awaited 结清，`tools/result` 同步登记异步兜底，下一动作必须等待结清，guard 也拒绝未结清窗口；命令同用该屏障；无可用落点一律拒绝，只读不豁免；结清失败保留结果、记缺口并限制后续动作；记录只含允许字段，不含参数或内容摘要 |
| 生命周期 | 卸载撤销 guard、监听器与服务；等待审批、前置审计或下游 listener 时卸载/取消，旧调用仍拒绝；已获准但结果未明的调用留下 `unknown` 缺口，不伪造完成、不重放；已挂载时拒绝再次挂载 |
| 安全 | 目录无效、受保护根模板未解析或宿主缺少 `tools.guard` 时拒绝挂载；路径不可判定按拒绝；**不提供 fail-open、通用 `run(command)` 或正则黑名单式保证** |

## IAM隔离许可算法

[私有算法](<src/iam-consumer.mjs>)与[显式测试入口](<src/isolated-testing.mjs>)已实现许可准备、原件同步复验、单次发送与结果收束；62项新例及210项policy全包回归通过，独立审阅关闭。它绑定实际执行对象、原arguments对象与摘要、原会话见证和原许可；不把operation或许可放进exec/arguments，不借新会话重试。

这些是局部算法与合成授权控制器证据，不是实际IAM、SDK工具或模型联合接通证明。普通apply没有注入这些私有来源。

[合成工具/命令入口](<src/iam-consumer-tools.mjs>)已在本地SDK-shaped注册链通过31项新例与241项policy回归，独立审阅关闭。原操作贯穿pre、审计、同步guard、callee等待与发送；owned finalizeContent在post后收束原操作，result观察者只清理、不撤回。IAM来源消失时工具闸仍留；owner卸载撤自己能力。命令内部执行标识由owned adapter生成，不是SDK Invocation字段。

[合成模型入口](<src/iam-consumer-models.mjs>)已实现，并经29项新例及270项policy回归验证，包含最终错误桥修复与独立复核。显式测试入口的模型工厂只装配控制器独享route，在实际进入owned adapter.stream时准备许可，不以metadata prepareCall或外层stream创建当作认证起点。原operation贯穿异步等待与流式片段检查，失效不借新许可继续；fixedLlmFailure只输出固定code/message，错误carrier按已核SDK ABI收敛。

这些是私有API的本地SDK-shaped证据，普通apply不启用、不改变默认模型、不接真实provider。根组合另有16项实际IAM工厂＋mock IdP联合验证，覆盖public/Basic及不同issuer/person整体替换；不是同issuer纯换人或真实提供方联调。maxRetries=0只约束内置与受控caller原操作，不证明任意恢复listener不会重试；已经输出的片段不能撤回。真实人员/用途、提供方权限及五分钟撤权仍需独立验收。

## 边界

- 工具自报的 `mutating` 仅作提示，读写与环境按可信目标与受控清单判定；无法分类的风险工具拒绝。
- 客户数据外发（C3）转本机确认，`never`、无 UI、取消、超时或异常均不视为确认。
- 工具门禁的审计记录包含动作、目标、工具、决策、规则、操作标识和结清耗时，不记参数正文；当前调用未自动传入主体，也不记录独立原因码。本包未配置时没有审计落点，受控动作因此拒绝；发行补丁显式配置的内存落点随进程退出丢失，持久落点需另行接入和验证。
- 客户端策略不能替代服务端授权；本机管理员可改配置，因此服务端仍须独立鉴权。
- 命令面：宿主当前版本没有全局命令拦截 seam，本包只能对**经本包登记**的命令兑现同一判定；其他插件注册的命令不在其内，不声称已覆盖。
