# @heluo/forge-policy

状态：可用（受控动作目录、统一门禁、受保护路径、C3 外发确认、有限委托与确认生命周期、必要审计前置骨架；未接企业环境，未做双端实机）

一句话：把"哪些动作可做"登记成目录，并在宿主工具管线与命令面上用同一判定兑现；目录无效、未登记、未开放、目标缺失或确认通道不可用时一律拒绝。

| 项 | 内容 |
|---|---|
| 形态 | Host 插件（提供 `policy` 服务） |
| 职责 | 工具门禁、路径规则、`$DSH_HOME` 硬拒绝、客户数据外发确认、决策审计 |
| 不负责 | 不替代服务端鉴权，不维护独立 hook 引擎 |
| 衔接点 | `tools.guard`（单调硬拒绝）、`tools/pre-execute`（需确认动作）、`ctx.commands`（命令面）、`otel` |
| 详细设计 | [详细设计](../../docs/design/plugins/forge-policy.md)（草案；§5.1 受控动作目录与统一门禁） |
| 实现状态 | 目录编译与判定、guard 与确认阶段、命令包装、受保护路径、C3 外发、决策审计与卸载清理已实现，并有离线用例与宿主探针覆盖；审批 UI 注册与超时、企业环境与双端实机未验 |

## 当前实现

| 项 | 状态 |
|---|---|
| 目录 | `compileCatalog`：字段校验、重复动作拒绝、缺省 `retry` 按 kind 推导；无效目录抛错而不是静默缩小 |
| 判定 | `decideAction`：未登记 / 未开放 / 目标缺失 / 出网禁止一律拒绝；`confirm` 类返回需确认；**自报 `readOnly` 等声明不参与任何规则**；写/确认动作每次执行复验组织批准（动作 + 实际资源 + 版本范围 + 当前时间，`prepare` 绑定、`guard` 重验，任一不满足即拒绝且零调用） |
| 工具面 | `ctx.tools.guard` 单调拒绝；必须持有同一执行对象的未消费审计收据，调用身份或参数变化即拒绝；`confirm` 动作还须经过确认阶段 |
| 命令面 | `policy.registerCommand`：未登记动作拒绝注册；判定、路径、确认、前置审计与结清复用工具屏障；简单命令须有明确目标，结构化命令提供 `resolveArguments(invocation)`，处理函数第二参数为规范化参数；命令名不能冒充目标 |
| 覆盖范围 | 只处理被显式登记为业务动作的工具，以及显式声明的类别（如 `bash → shell.exec`）；未登记的工具不属于本门禁作用域，不声称覆盖 |
| 受保护路径 | 根按 `$DSH_HOME/**` 模板解析（缺席回落 `~/.dsh`）；绝对化 + 词法折叠 + `realpath` + 平台大小写归一后判断包含；直接、穿越、symlink 别名一律拒绝，且**已获确认也不可翻转** |
| C3 外发确认 | 确认绑定 `(action, target, contentDigest)`；取消/过期/超时/不可用一律拒绝；渲染只出字段名与摘要前缀，并提供金丝雀检查 |
| 有限委托 | 纯 API 校验 principal、变更、仓库、动作及完整当前版本绑定；`source = host` 只是调用方约定，不是身份认证；可信 Host/实际会话承接尚需接线，不据此授予真实权限 |
| 确认生命周期 | 纯账本校验 `(action, target, contentDigest)` 与绑定版本并一次性消费；显式 key 只是定位提示，不替代当前 scope；新账本为空不证明实际恢复、分叉、子 Agent 已正确承接，真实生命周期接线需另验 |
| 必要审计 | 前置记录绑定同一执行对象及参数摘要；`tools/post-execute` awaited 结清，`tools/result` 同步登记异步兜底，下一动作必须等待结清，guard 也拒绝未结清窗口；命令同用该屏障；无可用落点一律拒绝，只读不豁免；结清失败保留结果、记缺口并限制后续动作；记录只含允许字段，不含参数或内容摘要 |
| 生命周期 | 卸载撤销 guard、监听器与服务；等待审批、前置审计或下游 listener 时卸载/取消，旧调用仍拒绝；已获准但结果未明的调用留下 `unknown` 缺口，不伪造完成、不重放；已挂载时拒绝再次挂载 |
| 安全 | 目录无效、受保护根模板未解析或宿主缺少 `tools.guard` 时拒绝挂载；路径不可判定按拒绝；**不提供 fail-open、通用 `run(command)` 或正则黑名单式保证** |

## 边界

- 工具自报的 `mutating` 仅作提示，读写与环境按可信目标与受控清单判定；无法分类的风险工具拒绝。
- 客户数据外发（C3）转本机确认，`never`、无 UI、取消、超时或异常均不视为确认。
- 审计记录主体、工具、决策、原因码与耗时，不记参数正文（落点由 P03 实现）。
- 客户端策略不能替代服务端授权；本机管理员可改配置，因此服务端仍须独立鉴权。
- 命令面：宿主当前版本没有全局命令拦截 seam，本包只能对**经本包登记**的命令兑现同一判定；其他插件注册的命令不在其内，不声称已覆盖。
