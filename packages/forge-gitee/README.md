# @heluo/forge-gitee

状态：规划

| 项 | 内容 |
|---|---|
| 形态 | 现有 `gh` 兼容 CLI 的只读工具面接入（规划） |
| 职责 | 查询仓库、Issue、PR，以命令白名单、凭据注入与策略门禁接入 |
| 不负责 | 不重写 Gitee API，不自建 MCP 或交叉编译，不把个人凭据写入仓库或模型上下文 |
| 衔接点 | bash 工具、企业策略门禁、凭据注入与审计（均待接口核验） |
| 详细设计 | [DESIGN-010](../../docs/design/plugins/forge-gitee.md)（草案，已建立） |
| 实现状态 | 尚未建立 `package.json`、源码与测试 |

## 边界

- CLI 版本、Windows / 麒麟 aarch64 产物、凭据方式与 JSON 字段稳定性仍待提供方核验，不把 `gh` 兼容输入当作双端已可用证据。
- 凭据按获准方案经环境注入，用户权限由 Gitee 服务端校验；不在 CLI 配置文件、仓库或模型上下文保存长期凭据。
- 一期仅开放经确认的只读命令，建分支、评论、提 PR 等写操作不在当前范围。
- CLI 前提不成立时关闭查询能力并提交替代形态评审，不自动恢复 MCP 或 arm64 交叉编译工作项。
