# 企业 Gitee 代码托管

集成企业 Gitee（`gh`）代码托管与 Git 工具，支持仓库、Issue 与 PR 查询及受控协同操作。

## 主要功能

- **仓库与协同查询**：查询仓库信息、Issue 列表与详情、PR 状态与代码差异。
- **受控协同与交付检查**：经确认后创建或评论 Issue/PR、发布评审记录、执行 `git commit` / `git push`，并支持发布就绪检查。
- **安全边界**：不执行合并（merge）、关闭（close）、回滚（revert）或删除标签等高危操作。

## 使用方式

1. 默认自动复用本机已认证的 `gh` 会话。
2. 可在设置面板调整 CLI 路径与超时，或在底部按需填写独立 Token。
