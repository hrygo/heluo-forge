# 企业 Gitee 代码托管

面向企业 Gitee 代码托管与研发交付流程的插件，结合兼容 `gh` 的 Gitee CLI 与本机 Git 工具提供结构化查询、受控写入与交付门禁校验。

## 核心能力

- **仓库与协同查询**：提供仓库信息、Issue 列表与详情、Pull Request 状态与差异查询，以及当前工作区代码版本快照。
- **受控协同动作**：经 `@heluo/forge-policy` 门禁放行与幂等保护，支持在授权场景下发起 Issue/PR 创建与评论、代码评审记录发布及本地 `git commit` / `git push`。
- **交付与关闭检查**：提供发布就绪判断与 `review.md` 审查一致性校核。
- **Gitee 环境设置**：可在设置面板调整 `cliPath` 与 `timeoutMs`，并在底部凭据区检测明文持久化凭据风险及按需指定独立 Token。

## 使用与凭据说明

1. 默认复用本机已认证的 `gh`（Gitee CLI）会话，无需额外在配置内填写凭据。
2. 在设置面板底部可按需指定仅对当前应用生效的独立 Token；如检测到本地明文配置文件会发出安全提示。

## 边界说明

- 不执行仓库合并（merge）、关闭（close）、回滚（revert）或标签删除等高危变更。
- 工具可见性不代替服务端仓库权限；实际访问与写入受企业 Gitee 权限体系约束。
