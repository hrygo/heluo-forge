# DOP 工作台

接入企业 DOP 研发协同工作台，一站式汇聚个人待办与研发进展看板，覆盖需求、项目、研发、测试与效能全流程，并在对话中协同澄清需求、梳理文档与拆解用户故事。

## 主要功能

- **跨平台待办与三大进展看板**：集中汇聚 7 路待办与「需求进展 / 实施进展 / 项目进展」三大看板，统计数字、阶段节点及卡片编号支持一键直跳 DOP 平台对应页面。
- **全流程协同与需求深读**：面向需求、项目、研发、测试、效能研发全生命周期；一期开放需求一句话起草、RMP 文档大纲检索联读与用户故事拆解/AC 澄清，生成标准提示词并由你确认后填入对话草稿箱。
- **统一企业账号认证与内网快速切换**：认证自动复用「企业账号（IAM）」登录态，无需单独维护静态 Token；内网环境支持企业私版预置、环境变量（`HELUO_DOP_BASE_URL` / `FORGE_DEVOPS_DOP_ENDPOINT`）自动生效，也可直接在下方「连接配置」保存热切换。

## 使用方式

1. 点击左侧边栏顶部 **DOP 工作台**（蓝橙小火箭图标），即可在右侧多页签栏打开工作台。
2. 如提示未配置 DOP 服务地址，请设置环境变量 `HELUO_DOP_BASE_URL`，或在插件详情页下方「连接配置」/ 工作台右上角「⚙ 定制 → 连接设置」填写并保存生效。
3. 如提示未登录，请先前往「设置 → 企业账号」完成 IAM 登录，再回到工作台点击重试。
