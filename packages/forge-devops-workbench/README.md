# DOP 工作台

接入企业 DOP 研发协同工作台，一站式汇聚个人待办与三大进展看板，覆盖需求、项目、研发、测试与效能全流程，并在对话中协同推进需求澄清与用户故事拆解。

状态：可用

## 使用方式

- 点击左侧边栏中的 **DOP 工作台**（蓝橙小火箭图标），即可在右侧打开工作台面板。
- 点击进展板数字、待办事项或需求/用户故事编号，可直接跳转 DOP 对应页面；点击卡片动作会先生成澄清或拆分提示词，由你确认后填入对话草稿箱。
- 认证方式统一自动复用「企业账号（IAM）」。公版默认不含企业内网域名，切换内网环境支持三种快捷方式（优先级由高到低）：
  1. 在插件详情页下方「连接配置」或工作台右上角「⚙ 定制 → 连接设置」填写 `apiBaseUrl`（示例 `https://dop.corp.example`）并保存热生效；
  2. 由企业私版发布配置直接注入 `apiBaseUrl`；
  3. 设置系统环境变量 `HELUO_DOP_BASE_URL`（或复用 `@heluo/forge-devops` 的 `FORGE_DEVOPS_DOP_ENDPOINT`），重启后自动生效。
