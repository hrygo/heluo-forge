# Enterprise DevOps

Integrates enterprise DevOps (`dop`) change queries and collaboration into chat.

## Features

- **Change Queries**: Look up pending items and change details with acceptance criteria.
- **Controlled Updates & Artifacts**: Update changes with confirmation and write plans or reports in your workspace.
- **Shortcut** (`/devops-change`): Start a change workflow quickly; configure `dop` path, timeout, and optional token in Settings.

## Usage

1. Reuses your existing local `dop` CLI session automatically.
2. If `dop` is not auto-detected, set its path or an optional workspace token in Settings.
