# 企业 DevOps 协同

面向研发协同流程的企业 DevOps 插件，通过受策略门禁约束的固定 CLI 适配器集成 `dop` 命令行能力与 Web 设置面板。

## 核心能力

- **变更查询与上下文聚合**：提供 `forge_devops_query`（单条变更详情与待办清单检索）与 `forge_devops_change_context`（组装包含约束与验收要点的变更上下文卡）。
- **受控变更更新与产物落盘**：提供 `forge_devops_change_update`（需显式确认回写标题、描述或验收标准）与 `forge_devops_write_artifact`（在工作区内输出结构化澄清、计划与报告产物）。
- **快捷入口与环境设置**（`/devops-change`）：安装后自动发现本机 `dop` 可执行入口；可在设置面板查看工具就绪状态、手动覆盖 CLI 路径与超时参数，并在面板底部按需指定独立 Token。

## 使用与凭据说明

1. 安装后默认复用本机已完成登录的 `dop` CLI 会话，无需额外环境变量。
2. 当自动发现未命中 `dop` 时，前往设置页面手动填写可执行文件位置或调整超时毫秒数（优先级：**配置页 > 环境变量 > 自动发现**）。
3. 面板底部的凭据区支持在当前工作区单独覆盖 Token（若同时启用企业账号服务则由宿主安全托管）。

## 边界说明

- 本插件聚焦 DevOps 变更协同能力，不包含代码仓库、Issue 与 Pull Request 操作（相关能力由 Gitee 插件提供）。
- 工具启用与参数放行受 `@heluo/forge-policy` 门禁策略约束；服务端业务权限由企业 DevOps 平台独立判定。
