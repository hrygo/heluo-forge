# 企业 DevOps 协同

集成企业 DevOps（`dop`）变更查询与协同能力，支持在对话中检索待办、查看变更上下文并按确认更新变更。

## 主要功能

- **变更查询与上下文**：检索待办清单与单条变更详情，自动整理约束与验收要点。
- **受控更新与产物**：经确认后更新变更信息，并在工作区生成计划或报告文档。
- **快捷入口**（`/devops-change`）：快速发起变更协同，并在设置面板管理 `dop` 路径、超时与独立 Token。

## 使用方式

1. 默认自动复用本机已登录的 `dop` CLI 会话。
2. 如未自动检测到 `dop`，可在设置面板手动指定路径或按需填写独立 Token。
