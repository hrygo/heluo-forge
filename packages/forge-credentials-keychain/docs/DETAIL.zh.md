# 企业加密凭据存储

为企业插件提供本地加密凭据托管能力的底层存储提供器，替代默认的明文凭据文件存储。

## 核心能力

- **值级加密落盘**：每条凭据记录与访问令牌均使用独立随机 IV 和 AES-256-GCM 单独加密后写入 `credentials.sqlite`，附加认证数据绑定属主与密钥版本。
- **跨进程一致性与锁控制**：多进程读写共享数据库级逻辑锁与短事务边界，避免并发覆盖与部分写入。
- **密钥隔离与旧文件拒绝**：密钥文件单独存放于同级 `*.keys/keyring.json` 目录；拒绝读取不受信任的旧版明文凭据文件。

## 安全与边界

- 本提供器需要由宿主组合策略启用（同时停用默认明文凭据提供器）。
- 日志和事件通道不输出令牌原文与敏感载荷。
- 本地权限检查与跨平台运行边界需结合操作系统账户隔离与目标机实际验证确认。
